# Quote Entity (Quotation)

## Overview

**Module**: Quote / Quotation
**Parent**: Generated from Opportunity (via P&L approval)
**Entry**: Sidebar -> OPPORTUNITY -> Quotation, or Opportunity detail -> Quotation(N) sub-tab

Quotes are formal sales documents generated from approved P&L analyses. They follow the "Locked Pair" pricing architecture and enter an approval workflow.

## Business Rules

1. **P&L-driven**: Quotes are generated from approved P&L analyses (video shows creation from Opportunity context) [V]
2. **Version correspondence**: P&L V1 -> Quote V1, P&L V2 -> Quote V2.
3. **Full audit trail**: Every version change is tracked.
4. **Tax calculation**: Global Tax setting applies to all line items; 8% SST (Malaysia) supported [V]
5. **Template-based export**: Uses Excel template (.xlsm) for document generation with PDF export option [V]
6. **Row limit enforcement**: Excel template has row limits; excess rows are warned and ignored [V]
7. **Auto-population**: Customer, Opportunity, Currency, Department auto-filled from parent Opportunity [V]

## Workflow

```
Opportunity -> P&L (approved) -> Quotation Create -> Save (draft) -> Submit (approval) -> Approved Quote
```

## Quotation Template Configuration (Video: Quotation Template Discussion.mp4)

### Excel Template Structure

The company uses an offline Excel template file (`SMMY Quotation^J SO and PI Template.xlsm`) for generating formal quotation documents. The template contains multiple sheets:
- **Quotation** -- Main quotation form
- **Sales Order** -- Auto-generated SO from quotation
- **Proforma Invoice(MYR)** -- MYR-denominated PI
- **Proforma Invoice(USD)** -- USD-denominated PI

The Excel template includes:
- **Company Header**: Securemetric Technology Sdn Bhd (759614-V), Kuala Lumpur address
- **Document Control**: Form No., Revision, QP No.
- **Customer Section**: TO, Attn, Tel, Fax, E-Mail
- **Order Details**: Date, Term, Sales Rep, Quotation NO, Ship Via
- **Line Items Table**: No, Item Code, Description, Quantity, Unit Price (RM), Total Excl Service Tax, Service Tax @ 8%, Total Incl Service Tax
- **Macros**: The template contains VBA macros for automation (`SECURITY WARNING: Macros have been disabled`)
