# 报价单实体 (Quote Entity)

## 概述

**模块**: 报价单 (Quotation)
**父级**: 从商机生成（通过P&L批准）
**入口**: 侧边栏 → 商机 → 报价单，或商机详情 → 报价单(N)子标签页

报价单是从已批准P&L分析生成的正式销售文档。它们遵循"锁定对"定价架构并进入审批工作流。

## 业务规则

1. **P&L驱动**: 报价单从已批准P&L分析生成（视频显示从商机上下文创建）[V]
2. **版本对应**: P&L V1 → 报价单V1，P&L V2 → 报价单V2。
3. **完整审计跟踪**: 每个版本变更都被跟踪。
4. **税计算**: 全局税设置应用于所有行项目；支持8% SST（马来西亚）[V]
5. **基于模板导出**: 使用Excel模板(.xlsm)进行文档生成，带PDF导出选项 [V]
6. **行数限制执行**: Excel模板有行数限制；超出行数被警告并忽略 [V]
7. **自动填充**: 客户、商机、货币、部门从父商机自动填充 [V]

## 工作流

```
商机 → P&L（已批准）→ 报价单创建 → 保存（草稿）→ 提交（审批）→ 已批准报价单
```

### 审批工作流（右侧边栏）
- **流程审批**面板带"跟踪"下拉
- **输入处理意见**文本域
- **常用评论**快速插入
- **上传附件**用于支持文档
- **提交**按钮（表头和侧边栏都有）
- **展开审批选项**链接用于自定义审批链 [V]

### Excel模板结构

公司使用离线Excel模板文件(`SMMY Quotation^J SO and PI Template.xlsm`)生成正式报价单文档。模板包含多个工作表：
- **报价单** — 主报价单表单
- **销售订单** — 从报价单自动生成的SO
- **形式发票(MYR)** — MYR计价PI
- **形式发票(USD)** — USD计价PI

Excel模板包括：
- **公司抬头**: Securemetric Technology Sdn Bhd (759614-V)，吉隆坡地址
- **文档控制**: 表单号、修订版、QP号
- **客户部分**: 收件人、联系人、电话、传真、邮箱
- **订单详情**: 日期、条款、销售代表、报价单编号、运输方式
