# SO实体（销售订单）

## 概述

**模块**: SO（销售订单）
**父级来源**: 从已批准的报价单生成
**入口**: 侧边栏 → 销售订单，或从商机详情 → 销售订单(N) 子标签页

销售订单代表已确认的客户订单，关联付款里程碑和交付。从报价单创建时自动填充商业信息。

## 业务规则

1. **报价转订单流程**: SO从已批准的报价单创建，自动填充商业信息 [V]
2. **数据继承**: 客户名称、商机、币种、订单金额从报价单自动填充 [V]
3. **实体自动填充**: 选择实体后自动填充实体代码和部门 [V]
4. **客户PO必填**: 提交前必须填写客户PO编号 [V]
5. **里程碑驱动开票**: 付款计划定义付款里程碑，非日期驱动 [V]
6. **项目经理确认要求**: 项目经理必须在开票前确认100%里程碑完成 [V]
7. **防止过早账单**: 里程碑未确认前不得开票 [V]
8. **分期付款支持**: 系统根据百分比自动计算应收金额（如 50% × 37,709.74 = 18,854.87）[V]

## 里程碑驱动结算流程

```
收到PO → 录入订单 → 形式发票 → 交付
                                ↓
                    项目经理确认100%完成
                                ↓
                       里程碑发票开具
```

## 工作流

```
报价单（已批准）→ 创建销售订单 → 保存（草稿）→ 提交（审批）→ 核对 → 生效SO
```

### 审批工作流（右侧边栏）
- **处理审批**面板，带"跟踪"下拉框
- **输入处理意见**文本区
- **常用意见**快捷插入
- **上传附件**用于支持文件（PO文件）
- **提交**按钮（顶部和侧边栏均有）
- **展开审批选项**链接用于自定义审批链 [V]

## 数据血缘（完整管道）

```
线索 → 联系人 → 客户 → 商机 → P&L → 报价单 → PO → 销售订单
```

每个阶段从前一阶段继承数据：
- **PO**继承自报价单：客户、商机、币种、总金额 [V]
- **SO**继承自报价单：客户、商机、币种、订单金额、交易类别 [V]
- **SO**还通过客户PO编号字段关联到PO [V]

**系统信息**（可折叠）:
- 创建人、创建时间、修改人、最后修改时间、状态（解锁）

**操作按钮**: 编辑（铅笔图标）、修改完成率、展开、关闭 [V]

**财务计算逻辑** [V]:
- `应收金额` = 订单总计 × 应收%（如 37,709.74 × 50% = 18,854.87）
- `未开票金额` = 应收金额 - 已开票金额
- `未收回金额` = 未开票金额（无收款时）
- 已收金额为空或零时状态为"未完成"
