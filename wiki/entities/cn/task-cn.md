# 任务实体（工作任务）

## 概述

**模块**: 工作任务
**入口**: 从任何实体详情页（商机、线索等）→ "新建任务"按钮，或活动侧边栏
**上下文**: 任务可关联到商机、线索、客户或联系人

任务是可分配的工作项，包含截止日期、优先级、执行人和进度跟踪。支持提醒、附件、子任务和反馈循环。

## 业务规则

1. **上下文创建**: 任务从父记录（商机/线索等）创建；关联类型和关联数据自动填充 [V]
2. **负责人 vs 执行人**: 负责人创建/拥有任务；执行人执行工作 [V]
3. **优先级级别**: 高 / 中 / 低 [V]
4. **双通道提醒**: 可同时通过待办和邮件通知 [V]
5. **进度跟踪**: 执行人通过滑块更新进度（0-100%）[V]
6. **反馈循环**: 任务反馈创建的条目在执行历史和任务反馈标签页可见 [V]
7. **审批工作流**: "待确认"状态表示已提交的工作等待负责人确认 [V]
8. **子任务支持**: 任务可有子级子任务 [V]
9. **完成锁定**: 任务标记完成后"任务已完成"按钮被禁用 [V]

## 任务工作流

```
任务创建 → 进行中 → 执行人更新进度 → 提交任务反馈 → 待确认 → 负责人确认 → 已完成
```

## 任务工作流状态

| 状态 | 颜色 | 描述 |
|------|------|------|
| 进行中 | 蓝色 | 正在处理的任务 |
| 待确认 | — | 已提交反馈，等待负责人确认 |
| 已完成 | 绿色 | 任务已完成并确认 |
