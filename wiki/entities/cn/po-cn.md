# PO实体（采购订单）

## 概述

**模块**: PO（采购订单 / 客户采购订单）
**父级来源**: 从商机或报价单创建
**入口**: 侧边栏 → 采购订单，或从商机详情 → PO(N) 子标签页，或商机上的"创建PO"按钮

客户采购订单代表从客户收到的正式商业承诺。在销售订单或合同生成之前创建。

## 业务规则（来自蓝图）

1. **SO前置条件**: 必须先录入PO才能生成销售订单或合同
2. **关联赢单商机**: PO记录是"已赢单"商机的子记录
3. **自动填充**: 系统从源报价单自动填充客户名称、总金额、币种
4. **手动录入**: 客户PO编号和PO文件上传为必填项
5. **商机状态更新**: 创建PO后，父商机状态更新为"已赢单" [V]
6. **生效状态**: 新PO记录以"生效"状态创建 [V]

## 工作流

```
商机（已赢单）→ 创建PO → 填写PO编号 + 上传文件 → 保存（草稿）→ 提交（审批）→ 生效PO
```

### 审批工作流（右侧边栏）
- **处理审批**面板，带"跟踪"下拉框
- **输入处理意见**文本区
- **常用意见**快捷插入
- **上传附件**用于支持文件
- **提交**按钮（顶部和侧边栏均有）
- **展开审批选项**链接用于自定义审批链 [V]

## 从报价单的数据继承

当从报价单创建PO时，以下字段自动填充：

| 字段 | 来源 |
|------|------|
| 客户 | 报价单 → 客户 |
| 商机 | 报价单 → 商机 |
| 币种 | 报价单 → 币种 |
| 总金额 | 报价单 → 行项目合计 |
| 交易类别 | 报价单 → 交易类别 |

## 商机中的PO上下文

商机详情视图在子表中显示关联的PO：
- **序号**列
- **PO编号**列（如 8596848）[V]

商机子标签页导航：详情、产品(N)、P&L(N)、报价单(N)、**PO(N)**、销售订单(N)、决策人地图(N)、竞争分析 [V]

## PO与SO的关系

- SO的"客户PO编号"字段回链到PO记录 [V]
- SO同时继承报价单和PO的数据 [V]
- PO是创建SO的前置条件 [V]
