# 重名检查实体

## 概述

**模块**: 重名检查
**入口**: 侧边栏 → CRM → DUPLICATE CHECK
**URL路径**: 待定（需要生成Schema）

专用模块，用于在创建新记录前查找现有客户或联系人。同时搜索两个实体并以分标签页显示结果。

## 搜索界面

![Duplicate Check Results](../assets/duplicate-check-001.png)

### 搜索栏
- **单一输入框** — 搜索所有可搜索字段
- **搜索目标**: 姓名、手机、邮箱、注册码（法人ID）
- **匹配行为**: 模糊匹配 — 匹配文本在结果中以黄色高亮显示
- **操作**: 搜索按钮（放大镜）+ 清除按钮（x）

### 结果汇总栏
- **找到总记录数** — 所有匹配的计数
- **联系人** — 联系人匹配计数
- **客户** — 客户匹配计数

### 结果标签页
- **客户(N)** — 客户记录标签页（默认）
- **联系人(N)** — 联系人记录标签页

### 结果表

| 列名 | 描述 |
|------|------|
| **序号** | 行号 |
| **姓名** | 客户/联系人姓名（匹配文本以黄色高亮） |
| **负责人** | 记录负责人（如 Soo, CK, Alan） |
| **实体** | 法人实体代码（如 PTSK, SMMY, SMPH） |
| **法人ID** | 注册码 / 唯一标识符 |

### 分页
- 页面导航: `< 1 >`
- 总项目数: "共 N 条"
- 页面跳转: "前往 X"（跳转到第X页）— ⚠️ 中文标签是缺陷
- 每页条数: "每页 10 条"（每页10条）— ⚠️ 中文标签是缺陷

## 业务规则

1. **跨实体搜索**: 单次搜索同时查询联系人和客户
2. **模糊匹配**: 返回部分匹配，不仅限于精确匹配
3. **高亮显示**: 匹配文本在结果名称中以黄色高亮
4. **标签分离**: 结果按实体类型分开，带数量徽章
5. **仅真实实体**: 仅返回真实数据库记录，不含草稿
