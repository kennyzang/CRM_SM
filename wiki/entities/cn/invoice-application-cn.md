# 开票申请实体（IR）

## 概述

**模块**: 开票申请（IR）— 售后收款工作流
**入口**: 侧边栏 → REVENUE → Invoice Application
**创建页**: "Invoice Application Create"
**URL路径**: `sys-modeling/app/km-ltc/add/...`
**ID格式**: `IRYYYYMMDDNNNN`（如 IR202605270004）

开票申请用于基于销售订单请求发票生成，有两种开票模式：**项目**（全额开票）和**里程碑**（按付款计划进度开票）。

## 侧边栏上下文 [V]

侧边栏的 **REVENUE** 区域包含：
- Payment Schedule
- **Invoice Application**（当前模块）
- Milestone Invoice
- Customer Payment
- Collection Details

## 业务规则

1. **两种发票类型**: Project（全额）vs Milestone（进度开票）[V]
2. **自动生成ID**: 开票申请ID、PI编号、参考号由系统生成 [V]
3. **SO依赖**: 必须选择销售订单；继承客户、币种、行项目 [V]
4. **服务税**: 自动应用8% SST [V]
5. **里程碑开票**: 当发票类型="Milestone"时，用户从付款计划记录中选择 [V]
6. **里程碑类型**: "By Products" 或 "By Percentage" [V]
7. **选择记录弹窗**: 对于里程碑发票，打开按销售订单ID过滤的查找弹窗 [V]
8. **PDF导出**: 形式发票可预览并导出为PDF [V]
9. **审批工作流**: 提交触发带数字签名的BPM审批链 [V]
10. **产品行项目**: 从销售订单自动填充；包含服务周期（Year1等）[V]

## 工作流

```
销售订单 → 创建开票申请 → 选择发票类型 → 填写详情
       ↓
  Project类型: 行项目从SO自动填充 → 提交
       ↓
  Milestone类型: 选择付款计划 → 定义里程碑 → 提交
       ↓
  审批工作流 → 发票生成 → 客户付款
```

## 选择记录弹窗（Milestone类型）[V]

在Milestone模式下选择付款计划ID时：

**过滤字段**:
- 销售订单ID（下拉）
- 付款类型（文本输入）
- 应收金额（数字输入）
- 应收%（数字输入）
- 付款计划ID（文本输入）

**网格列**:
- 序号（单选按钮用于选择）
- 付款计划ID（如 PP202605270004）
- 里程碑名称（如 "Installation"）
- fd_milestone_product（如 "Software 10% Hardware 20%"）
- 工作内容

**操作**: 确认、取消
