# 合同实体

## 概述

**模块**: 合同
**父级来源**: 从销售订单创建
**入口**: 从SO详情页 → 合同标签页 → 创建，或侧边栏 → 销售订单 → 合同

合同是与销售订单关联的法律协议。包含有效期、附件和自动到期提醒。

## 字段注册表（视频确认 [V]）

### 合同创建表单

| 字段标签 | data-tid | 必填 | 类型 | 备注 |
|----------|----------|------|------|------|
| 合同标题 | — [V] | 是 | 文本输入 | 如 "ABC NDA" |
| 合同编号 | — [V] | 自动 | 只读 | "自动生成" — 保存时系统分配 |
| 销售订单 | — [V] | 是 | 查找/引用 | 从父SO预填充（如 "SC/SO26/000005"）；有清除(x)和链接图标 |
| 客户 | — [V] | 是 | 查找 | 从销售订单自动填充（如 "ABC"） |
| 签署日期 | — [V] | 是 | 日期选择器 | 合同签署日期 |
| 到期日期 | — [V] | 是 | 日期选择器 | 合同到期；带月份导航的日历控件 |
| 备注 | — [V] | 否 | 文本区域 | 占位符"输入" |
| 附件 | — [V] | 否 | 文件上传 | "上传附件"按钮 + 带删除的文件列表 |

### 提醒区域

| 字段 | 类型 | 备注 |
|------|------|------|
| 通知对象 | 用户查找 | 选择到期前通知的用户 |
| 到期日前X天通知 | 数字输入 + 下拉选择 | 如 "5" + "天" |

### 提醒表工具栏

- **+ 添加行** — 添加更多提醒规则
- **导入** — 批量导入提醒
- **更多** — 下拉菜单含额外操作
- **撤销** — 折叠/展开区域

### 行操作

- **插入** — 在上方添加行
- **复制** — 复制行
- **删除** — 删除行

## 业务规则

1. **SO驱动创建**: 合同从销售订单创建；销售订单和客户字段预填充 [V]
2. **自动编号**: 合同编号由系统自动生成 [V]
3. **到期提醒**: 系统支持合同到期前X天的自动通知 [V]
4. **多提醒支持**: 每个合同可配置多条提醒规则 [V]
5. **文档附件**: 合同支持文件附件（PDF等）[V]

## 合同详情页（推断）

基于创建流程和SO详情页标签页：
- SO详情页的合同标签页显示关联的合同（Contract(0)、Contract(1)等）
- 合同列表包含序号和合同标题列

## 工作流

```
销售订单（生效）→ 创建合同 → 填写表单 → 保存 → 合同生效
                                                    ↓
                                          到期提醒触发
```
