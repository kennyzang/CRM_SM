# 管道看板实体

## 概述

**模块**: CRM Pipeline（管道看板仪表盘）
**入口**: 侧边栏 → CRM → Pipeline
**URL路径**: 待定（需要生成Schema）

单页仪表盘，让每位团队成员一目了然地了解自己的项目在整个销售周期中所处的位置。以表格视图显示所有活跃交易，顶部有阶段汇总栏。

> **注意**: 尽管功能名称称为"看板"（Kanban），实际UI是**列表/表格视图**，顶部有阶段汇总栏 — 不是带有拖拽列的卡片式看板。

## 管道阶段定义

CRM使用**6阶段管道**（截图确认）：

| 阶段 | 位置 | 颜色 | 描述 |
|------|------|------|------|
| **LEAD** | 1 | 蓝色 | 初始线索捕获 |
| **OPPORTUNITY** | 2 | 蓝色 | 线索资格认定，商机已创建 |
| **QUOTATION** | 3 | 蓝色 | 从已批准P&L生成报价单 |
| **PO** | 4 | 蓝色 | 收到客户采购订单 |
| **SALES ORDER** | 5 | 蓝色 | 内部创建销售订单 |
| **PAYMENT** | 6 | 绿色 | 收到付款 / 成交 |

> ⚠️ **注意**: DOCX描述提到5个阶段（Lead → Opportunity → PO → SO → Payment），但实际UI显示**6个阶段**，QUOTATION作为OPPORTUNITY和PO之间的独立阶段。

## 页面布局

### 1. 管道汇总栏（顶部区域）

![Pipeline Summary Bar](../assets/pipeline-kanban-001.png)

六个阶段横向平铺显示，每个显示：
- **阶段名称**（如 LEAD、OPPORTUNITY）
- **交易数量**（该阶段的活跃项目数）
- **管道价值** 以分支机构默认币种显示（如 MYR）

**示例数据**（来自截图）：

| 阶段 | 数量 | 价值（MYR） |
|------|------|-------------|
| LEAD | 3 | 102,915.13 |
| OPPORTUNITY | 0 | 0 |
| QUOTATION | 1 | 430,650 |
| PO | 1 | 430,650 |
| SALES ORDER | 2 | 861,300 |
| PAYMENT | 12 | 695,211 |

**交互**: 点击任意瓷砖筛选下方项目列表，仅显示该阶段的项目。"重置"按钮恢复完整视图。

### 2. 筛选栏

| 筛选条件 | 类型 | 选项 |
|----------|------|------|
| **TIME** | 切换按钮 | 今年 / 本月（默认）/ 自定义 |
| **ENTITY** | 下拉 | 全部 / 特定实体 |
| **REP** | 下拉 | 全部 / 特定销售代表 |
| **重置** | 按钮 | 清除所有筛选 |

### 3. 汇总行

文本格式: `显示 **N** 笔交易 • 管道 **MYR X,XXX,XXX.XX**`

### 4. 管道交易表格

| 列名 | 描述 |
|------|------|
| **项目** | 项目/客户名称（可点击 → 导航到详情页） |
| **金额** | 以分支机构默认币种显示的交易价值 |
| **代表** | 分配的销售代表（如 YCK） |
| **管道阶段** | 可视化圆点轨迹进度指示器 + 阶段名称标签 |

**圆点轨迹进度指示器**: 代表6个阶段的水平圆点行。实心圆点 = 已完成阶段，高亮环 = 当前阶段，空心圆点 = 未来阶段。阶段名称作为标签显示在末端。

## 业务规则

1. **币种一致性**: 所有货币金额以分支机构默认币种显示 — 无货币转换或混合币种。
2. **阶段筛选**: 点击阶段瓷砖筛选列表；重置恢复完整视图。
3. **导航**: 点击任意项目行直接导航到该项目完整详情页。
4. **搜索**: 右上角搜索栏支持按项目名称、代表名称或记录ID实时筛选。
5. **时间筛选**: 支持今年 / 本月 / 自定义日期范围。
6. **实体/代表筛选**: 可将管道范围限定到特定实体或销售代表。

### 主内容区
- 标题: "CRM Pipeline"
- 搜索输入: "Search project or rep..."
- 6个阶段瓷砖 + 数量 + 价值
- 筛选栏（TIME / ENTITY / REP / 重置）
- 汇总行
- 管道交易表格 + 徽章（如 "19 records"）

## 数据流

```
Lead → Opportunity → Quotation → PO → Sales Order → Payment
  ↓         ↓            ↓         ↓         ↓          ↓
Stage 1   Stage 2      Stage 3   Stage 4   Stage 5    Stage 6
```

每个阶段从其对应的实体模块聚合并显示数量 + 总价值。
