# Contract Entity

## Overview

**Module**: Contract (合同)
**Parent**: Created from Sales Order
**Entry**: From SO Details page → Contract tab → Create, or Sidebar → SALES ORDER → Contract

Contracts are legal agreements linked to Sales Orders. They include validity periods, attachments, and automated expiry reminders.

## Field Registry (Video-Confirmed [V])

### Contract Create Form

| Field Label | data-tid | Required | Type | Notes |
|-------------|----------|----------|------|-------|
| Contract Title | — [V] | Yes | Text Input | e.g., "ABC NDA" |
| Contract ID | — [V] | Auto | Read-Only | "Auto Generate" — system-assigned on save |
| Sales Order | — [V] | Yes | Lookup/Reference | Pre-filled from parent SO (e.g., "SC/SO26/000005"); has clear (x) and link icon |

### Reminder Section

| Field | Type | Notes |
|-------|------|-------|
| Notify Who | User Lookup | Select user(s) to notify before expiry |
| Notify X day(s) before Expiry Date | Number Input + Dropdown | e.g., "5" + "day" |

### Reminder Table Toolbar

- **+ Add rows** — add more reminder rules
- **Import** — bulk import reminders
- **More** — dropdown with additional actions
- **Revoke** — collapse/expand section

### Row Actions

- **Insert** — add row above
- **Copy** — duplicate row
- **Delete** — remove row

## Business Rules

1. **SO-driven creation**: Contract is created from a Sales Order; Sales Order and Customer fields are pre-filled [V]
2. **Auto-numbering**: Contract ID is auto-generated by the system [V]
3. **Expiry reminders**: System supports automated notifications X days before contract expiry [V]
4. **Multi-reminder support**: Multiple reminder rules can be configured per contract [V]
5. **Document attachment**: Contracts support file attachments (PDF, etc.) [V]

## Contract Details Page (inferred)
