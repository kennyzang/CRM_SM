## TC-001 - 线索转化 - 服务团队与活动记录继承验证

| 字段 | 值 |
|------|----|
| **模块** | 线索 |
| **类别** | 数据继承 |
| **角色** | 销售代表 |
| **优先级** | P1 |

### 前置条件

线索已存在，包含 2 名服务团队成员（负责人 + 成员）及 3 条活动记录

### 测试步骤

1. 进入线索详情页
2. 确认服务团队有 2 名成员
3. 确认活动记录有 3 条
4. 点击「转化」启动两步转化向导
5. 第一步（客户）：验证/创建客户，继续
6. 第二步（商机）：确认所有 6 个复制选项默认勾选
   - 复制团队至：客户、联系人、商机
   - 复制活动至：客户、联系人、商机
7. 取消勾选「复制活动至 -> 商机」
8. 完成转化
9. 进入新建客户 -> 检查服务团队
10. 进入新建联系人 -> 检查销售记录标签页
11. 进入新建商机 -> 检查服务团队与活动记录

### 预期结果

1. 客户服务团队包含线索的两名团队成员
2. 联系人销售记录包含线索的全部 3 条活动
3. 商机服务团队包含线索的两名团队成员
4. 缺陷回归：商机活动记录不应包含线索活动（复选框已取消勾选）- 验证是否符合预期
5. 线索状态变更为「已转化」（绿色徽章）
6. 转化记录标签页显示含时间戳的转化历史

## TC-002 - 线索转化 - 多币种金额计算（IDR 转 MYR）

| 字段 | 值 |
|------|----|
| **模块** | 线索 |
| **类别** | 数据继承 |
| **角色** | 销售代表 |
| **优先级** | P1 |

### 前置条件

线索已存在：货币=IDR、预估交易金额=100,000,000、胜率=25%

### 测试步骤

1. 进入线索详情
2. 记录预估交易金额（100,000,000 IDR）与胜率（25%）
3. 点击「转化」-> 第二步（商机）
4. 确认货币默认为 IDR
5. 输入汇率：0.000223（IDR->MYR）
6. 验证 MYR 金额自动计算：100,000,000 x 0.000223 = 22,300 MYR
7. 验证加权金额 = MYR 金额 x 胜率 = 22,300 x 25% = 5,575 MYR
8. 完成转化
9. 进入新建商机 -> 验证财务字段

### 预期结果

1. MYR 金额 = 22,300.00（精确计算：100,000,000 x 0.000223）
2. 加权金额 = 5,575.00（22,300 x 0.25）
3. 商机货币 = IDR
4. 实体反映选定实体（SCMY 或 PTSM）
5. 销售记录字段从线索活动历史自动填充
6. 联系人标签输入从线索联系人表自动带入

## TC-004 - 线索导入 - 枚举验证与重复检查

| 字段 | 值 |
|------|----|
| **模块** | 线索 |
| **类别** | 导入验证 |
| **角色** | 销售经理 |
| **优先级** | P2 |

### 前置条件

已准备含 17 列的 Excel 模板（9 个必填项，8 个可选项）

### 测试步骤

1. 进入线索列表 -> 点击导入按钮
2. 选择导入模式 = 「新增与更新导入」（UPSERT）
3. 设置条件字段 = 「线索名称」
4. 上传含测试数据的 Excel 模板：
   - 第1行：有效数据，线索等级=「A级」，来源=「搜索引擎」
   - 第2行：无效线索等级=「D级」（不在枚举内）
   - 第3行：线索名称与现有记录重复
   - 第4行：锁定状态=「1」（数字 -> 应映射为「未锁定」）
5. 点击确认导入
6. 查看导入结果

### 预期结果

1. 第1行导入成功
2. 第2行验证失败 - 线索等级「D级」不在允许值内（A/B/C级）
3. 第3行更新现有记录（UPSERT模式）
4. 第4行锁定状态正确映射：1=未锁定，2=已锁定
5. 导入摘要显示：N条成功，M条失败，K条更新
6. 所有导入数据在线索队列列表中可见
7. 枚举验证：线索等级（3值）、来源（7值）、线索队列（2值）、业务流程（2值）

## TC-006 - 商机阶段推进 - 五阶段销售漏斗与胜率

| 字段 | 值 |
|------|----|
| **模块** | 商机 |
| **类别** | 销售漏斗流程 |
| **角色** | 销售代表 |
| **优先级** | P1 |

### 前置条件

商机处于「资格审查」阶段（胜率25%）

### 测试步骤

1. 进入商机详情
2. 确认当前阶段 = 「资格审查」，胜率徽章25%
3. 点击「推进到下一阶段」
4. 确认阶段变更为「方案/POC」（50%）
5. 确认加权金额重新计算：预估金额 x 50%
6. 再次点击「推进到下一阶段」
7. 确认阶段变更为「价格谈判」（75%）
8. 点击「推进到下一阶段」-> 选择「成交」
9. 确认阶段变更为「成交」（100%）
10. 确认状态徽章变更为「已赢单」（绿色）
11. 尝试从「成交」继续推进 -> 应被阻止

### 预期结果

1. 阶段推进顺序：资格审查(25%) -> 方案/POC(50%) -> 价格谈判(75%) -> 成交(100%)
2. 每次推进重新计算加权金额 = 预估金额 x 胜率
3. 成交后：状态=「已赢单」，漏斗阶段=100%
4. 成交是终止阶段 - 不可继续推进
5. 丢单（0%）也是终止阶段
6. 所有阶段推进均为手动（蓝图规定，无自动推进）

## TC-011 - 损益表财务摘要 - 利润率计算准确性（加价法 vs 毛利率）

| 字段 | 值 |
|------|----|
| **模块** | 损益表 |
| **类别** | 财务计算 |
| **角色** | 销售代表 |
| **优先级** | P1 |

### 前置条件

损益表存在：2个软件产品（定价：5000、3000）和1个硬件产品（成本：2000）

### 测试步骤

1. 进入损益表创建/详情页
2. 添加 2 个软件产品：
   - 产品A：定价=5,000，加价=20% -> 销售价格=6,000
   - 产品B：定价=3,000，加价=10% -> 销售价格=3,300
3. 添加 1 个硬件产品：
   - 单位成本=2,000，预期利润=500 -> 销售价格=2,500
4. 验证财务摘要卡片：
   - 总收入 = 6,000 + 3,300 + 2,500 = 11,800
   - 总成本 = 软件成本 + 2,000
   - 总利润 = 总收入 - 总成本
   - 利润率 % = （总利润 / 总收入）x 100
5. 验证每条明细利润率 = （利润 / 售价）x 100（毛利率公式）
6. 确认当利润率 < 目标利润率时出现红色警告图标

### 预期结果

1. 关键：系统使用毛利率公式（利润/售价）x100
2. 软件：销售价格 = 定价 x（1 + 加价%）
3. 硬件：销售价格 = 成本 + 预期利润
4. 总收入卡片：蓝色文字，所有销售价格之和
5. 总利润卡片：绿色文字（收入 - 成本）
6. 利润率卡片：>= 目标时绿色，< 目标时红色
7. 利润率 < 目标的明细行显示红色感叹号警告图标
8. 所有数字自动计算

| **角色** | 销售代表 |
| **优先级** | P1 |

### 前置条件

损益表处于草稿状态，方案架构师用户已存在

### 测试步骤

1. 以销售代表（发起人）登录
2. 进入损益表详情 -> 流程审批侧边栏
3. 设置操作 = 「协作」（非「提交」）
4. 选择接收人 = 「方案架构师」（通过用户选择器）
5. 添加协作备注：「请审查硬件定价」
6. 点击提交 -> 表单编辑权限转移给接收人

8. 从待办事项打开损益表 -> 点击编辑（铅笔图标）
9. 修改硬件成本，添加专业服务明细
10. 点击「提交回」-> 返回给销售代表
11. 以销售代表登录 -> 确认变更可见
12. 销售代表可继续分配其他协作人，或点击「提交」进入审批

### 预期结果

1. 协作将编辑权限从发起人转移给接收人
2. 接收人在消息中心收到待办事项
3. 接收人可编辑所有字段并添加/删除明细
4. 「提交回」将权限归还发起人
5. 发起人可与不同协作人重复循环
6. 协作完成后发起人才能点击「提交」进入审批流
7. 协作与审批不同 - 协作期间不经过部门负责人/财务路由

## TC-014 - 损益表审批工作流 - 基于利润率的路由条件

| 字段 | 值 |
|------|----|
| **模块** | 损益表 |
| **类别** | 审批路由 |
| **角色** | 销售经理 |
| **优先级** | P1 |

### 前置条件

损益表含：产品A利润率=15% < 目标20%，产品B利润率=25% >= 目标20%

### 测试步骤

1. 进入损益表详情
2. 查看明细：
   - 产品A：利润率=15%，目标=20% -> 低于目标
   - 产品B：利润率=25%，目标=20% -> 高于目标
3. 在流程审批侧边栏点击「提交」
4. 追踪审批路由
5. 确认路由至部门负责人（因产品A利润率 < 目标）
6. 测试场景：所有产品利润率 >= 目标 -> 确认自动审批
7. 测试场景：总利润率 < 目标 -> 确认路由至财务团队

### 预期结果

1. 审批路由规则（蓝图 + DOCX）：
   - 任意明细利润率 < 目标 -> 路由至部门负责人
   - 包含关键产品 -> 路由至部门负责人（尚未配置）
