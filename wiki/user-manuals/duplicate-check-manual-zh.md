## 1. 模块概述

**重名检查**（Duplicate Check）模块允许您在创建新客户或联系人之前搜索系统中是否已存在相同记录。这有助于防止重复录入，确保 CRM 数据质量。

### 1.1 入口

- **侧边栏**: 导航至 **CRM → DUPLICATE CHECK（重名检查）**

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| 跨实体搜索 | 一次搜索同时查询联系人和客户 |
| 模糊匹配 | 部分文本匹配，搜索结果高亮显示 |
| 分标签结果 | 按实体类型分类显示，带数量徽章 |
| 快速导航 | 点击结果可查看或编辑完整记录 |

## 2. 搜索界面

![重名检查搜索](../assets/duplicate-check-001.png)

### 2.1 搜索栏

搜索栏是查找潜在重复项的主要输入：

- **单个输入框** — 在此输入搜索关键词
- **搜索目标**: 名称、手机、邮箱、注册代码（Legal ID）
- **清除按钮**（x）— 清除当前搜索文本
- **搜索按钮**（放大镜）— 执行搜索

### 2.2 搜索步骤

1. 在搜索栏中输入关键词（例如 "Enterprise"、电话号码或邮箱地址）
2. 点击 **搜索** 按钮或按 **Enter** 键
3. 结果将显示在下方，同时展示来自联系人和客户的匹配结果

## 3. 搜索结果

### 3.1 结果汇总栏

搜索后，汇总栏显示总匹配数：

- **找到 X 条记录** — 所有实体的总匹配数
- **Y 个联系人** — 联系人匹配数量
- **Z 个客户** — 客户匹配数量

### 3.2 结果标签页

结果分为两个标签页：

- **Customers（客户）**（Z 条）— 匹配的客户记录（默认标签）
- **Contacts（联系人）**（Y 条）— 匹配的联系人记录

### 3.3 结果表格

| 列名 | 说明 |
|------|------|
| **No.（序号）** | 行号 |
| **Name（名称）** | 客户或联系人名称 — 匹配文本以 **黄色高亮** 显示 |
| **Owner（负责人）** | 记录负责人（如 Soo、CK、Alan） |
| **Entity（实体）** | 法人实体代码（如 SMMY、SCMY、SMPH、PTSK） |
| **Legal ID（法定 ID）** | 注册代码或唯一标识符 |

### 3.4 模糊匹配高亮

当您搜索一个关键词（如 "enter"）时，系统会执行模糊匹配并**在结果名称中黄色高亮匹配文本**：

- "Unified Data **Enter**prises (M) Sdn Bhd"
- "Elite **Enter**prise Solutions Sendirian Berhad"
- "Elite Technology **Enter**prises (M) Sdn Bhd"

## 4. 结果导航

### 4.1 分页

结果表格底部：

- **页面导航**: `< 1 2 3 >` — 点击切换页面
- **总条数**: "Total of X items" — 所有页面的总记录数
- **跳转**: 输入页码后点击跳转
- **每页条数**: 下拉菜单设置每页显示的结果数（默认：10 条）

### 4.2 查看记录

点击结果表格中的任意行，可跳转至该记录的完整详情页。在此您可以：

- 查看完整的记录详情
- 如有权限，可编辑该记录
- 与您准备创建的新记录进行对比

---

## 5. 业务规则

1. **跨实体搜索**: 一次搜索同时查询联系人和客户数据库。
2. **模糊匹配**: 系统返回部分匹配结果，而不仅是精确匹配。这有助于发现近似重复项。
3. **高亮显示**: 匹配文本在结果名称中以黄色高亮显示，便于识别。
4. **仅真实记录**: 仅返回真实数据库记录 — 草稿或未提交的记录不包含在内。
5. **实体范围**: 结果包含您账户可见的所有法人实体的记录。

## 6. 常见问题

**Q: 什么时候应该使用重名检查？**
在创建任何新客户或联系人之前，先在重名检查中搜索。这可以防止创建重复记录，保持 CRM 数据清洁。

**Q: 可以按电话号码搜索吗？**
可以。在搜索栏中输入电话号码，系统将在联系人和客户的手机字段中进行搜索。

**Q: 如果找到重复项怎么办？**
如果找到与您准备创建的记录相匹配的已有记录，请改用现有记录。您可以打开它，查看详情，并直接向其中添加新信息。

**Q: 重名检查可以对线索（Lead）使用吗？**
不可以。重名检查仅搜索联系人和客户。线索在创建过程中有自己的重复验证机制。

**Q: 为什么有些搜索结果有高亮而有些没有？**
只有与搜索关键词匹配的文本才会高亮显示。如果一条记录出现在结果中但没有高亮，它可能是在表格中未显示的字段中匹配（例如匹配的邮箱地址）。

**Q: 可以按注册代码 / Legal ID 搜索吗？**
可以。在搜索栏中输入公司的注册代码（如 "171949580394"）来查找具有相同或相似 Legal ID 的客户。
