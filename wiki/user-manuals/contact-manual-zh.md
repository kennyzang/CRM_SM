## 1. 模块概述

联系人（Contact）是与客户关联的个人。每个联系人必须链接到已有的客户记录。

### 1.1 入口路径

- **侧边栏**: 导航至 **Contact Person（联系人）**
- **从线索**: 线索创建表单 → 联系人表 → "新建联系人"
- **从客户**: 客户详情 → 联系人标签页

### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| 联系人创建 | 创建链接到客户的个人联系人 |
| 关系图 | 可视化联系人之间的关联关系 |
| 联系人搜索 | 按姓名、电话、邮箱或公司搜索 |
| 批量导入 | 从 Excel 模板导入联系人 |

## 3. 创建联系人

![联系人创建表单](../assets/contact-002.jpg)

### 3.1 入口

点击联系人列表工具栏上的 **+ 创建** 按钮，或点击线索的联系人表中的 **"新建联系人"** 按钮。

### 3.2 基本信息

| 字段 | 必填 | 类型 | 备注 |
|------|------|------|------|
| 客户 | 否 | 关联/查找 | 标签样式，可点击 'x' 清除 |
| 联系人名称 | 是 | 文本 | 红色星号表示必填 |
| 手机 | 否 | 文本 | 马来西亚格式：01x-xxxxxxx。自动补全历史输入 |
| 邮箱 | 否 | 文本 | 邮箱或手机至少填一项 |
| 部门 | 否 | 文本 | 占位符："请输入" |
| 职位 | 否 | 文本 | CRM 中字段名为 "position" |
| 性别 | 是 | 单选 | 选项：男 / 女 |
| 类型 | 是 | 下拉 | 值包括"客户联系人" |
| 地址 | 否 | 文本 | 公司地址 |
| 生日 | 否 | 日期选择器 | 日历图标，占位符："请选择日期" |
| 汇报给 | 否 | 关联/查找 | 链接到另一个联系人 |
| 关系 | 否 | 下拉 | 教练(5)/冠军(4)/支持者(3)/中立(2)/阻碍者(1) |
| 推荐人 | 否 | 文本 | 占位符："请输入" |
| 决策者 | 否 | 单选 | 选项：是 / 否 |
| 决策角色 | 否 | 下拉 | 占位符："请选择" |
| 办公电话 | 否 | 文本 | 占位符："请输入" |
| 名片 | 否 | 文件上传 | 仅 jpg/gif/png，单文件，拖拽上传 |
| 备注 | 否 | 文本域 | 补充说明 |
| 负责人 | 否 | 只读 | 自动填充（当前用户） |
| 负责人部门 | 否 | 只读 | 未设置时显示"-" |

### 3.3 底部操作

填写必填字段后，点击 **保存** 或 **保存并新建** 创建联系人。

> ⚠️ **重要**: 邮箱或手机至少必须填写一项才能提交。

## 4. 联系人详情

### 4.1 联系信息

详情页以只读模式显示所有联系人字段，包括：
- 基本信息：姓名、客户、手机、邮箱、部门、职位
- 关系信息：关系评分、推荐人、决策者状态
- 地址和名片（如已上传）

### 4.2 编辑联系人

点击 **编辑** 按钮修改联系人详情。变更会针对重复记录进行验证。

---

## 5. 联系人关系图

CRM 支持联系人关系图，展示同一客户组织内联系人之间的关联关系。这有助于销售团队了解决策网络。

## 6. 常见问题与注意事项

### 6.1 业务规则

1. **客户关联**: 每个联系人必须关联到一个客户记录
2. **邮箱或手机**: 至少填写邮箱或手机中的一项才能提交
3. **性别字段**: 单选按钮 — 通过匹配字段集标签文本解析
4. **重复验证**: 保存时系统自动与数据库验证唯一性
5. **负责人自动分配**: 负责人字段自动填充为当前登录用户

### 6.2 关系评分

| 关系 | 评分 | 描述 |
|------|------|------|
| 教练（Coach） | 5 | 积极帮助你赢得订单 |
| 冠军（Champion） | 4 | 在内部为你的方案代言 |
| 支持者（Supporter） | 3 | 态度积极但不主动帮忙 |
| 中立（Neutral） | 2 | 没有强烈倾向 |
| 阻碍者（Blocker） | 1 | 反对你的方案 |

### 6.3 已知问题

- 性别字段没有 `data-tid` 属性 — 通过匹配字段集标签文本解析
- 通过弹窗创建联系人时，`window.close()` 可能干扰自动化
- CRM 拼写错误：备注字段使用 `teaxtarea`（非"textarea"）
