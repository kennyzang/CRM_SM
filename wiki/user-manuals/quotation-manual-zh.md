## 1. 模块概述

报价单（Quotation）是从已批准 P&L 分析生成的正式销售文档。报价单遵循"锁定对"定价架构，并进入审批流程。

### 1.1 核心特征

| 特征 | 描述 |
|------|------|
| P&L 驱动 | 从已批准的 P&L 分析生成 |
| 版本锁定 | P&L V1 → 报价单 V1，P&L V2 → 报价单 V2 |
| 自动填充 | 客户、商机、币种、部门从父级继承 |
| 需要审批 | 定稿前进入审批流程 |

### 1.2 入口路径

- **从商机**: 商机详情 → 报价单(N) 标签页 → +创建
- **侧边栏**: OPPORTUNITY → Quotation
- **打开方式**: 以**滑出面板**形式打开在商机详情之上

## 2. 报价单入口

### 2.1 从商机详情进入

1. 导航到一个商机
2. 点击 **报价单(N)** 标签页
3. 点击 **+创建** 打开报价单创建滑出面板
4. 商机详情面板在背景中保持可见但变暗

### 2.2 已有报价单表格

| 列 | 描述 |
|----|------|
| 序号 | 行号 |
| 报价单 ID | 格式：SM/26/YCK/A... |
## 3. 创建报价单

### 3.1 入口

从商机详情页面点击 **"+ Create Quotation"** 打开报价单创建滑出面板。

![报价单创建面板](../assets/quotation-001.jpg)

### 3.2 头部信息

| 字段 | 必填 | 类型 | 备注 |
|------|------|------|------|
| 报价单标题 | 是 | 文本 + 自动补全 | 自动补全建议已有名称（如"...Quotation2"） |
| P&L | 是 | 查找 | P&L ID（如 2026052700008） |
| 币种 | 自动 | 文本 | 自动填充"MYR" |
| 部门 | 否 | 标签输入 | 如"SMMY"，可点击 'x' 移除 |
| 商机 | 自动 | 只读 | 父商机名称 |
| 发货方式 | 否 | 下拉 | 标准/快递/隔夜/优先/经济/空运/陆运 |
| 付款条件 | 否 | 文本 | 如"Refer to T&C" |
| 销售代表 | 自动 | 文本 | 自动填充（如"YCK"） |
| 报价日期 | 自动 | 日期选择器 | 自动设为当前日期 |
| 联系人（Attn） | 否 | 下拉 | 占位符"Select" |
| P&L ID | 自动 | 只读 | 与 P&L 查找值相同 |
| 地址 | 自动 | 文本域 | 从客户自动填充 |

### 3.2 客户信息（TO）部分

| 字段 | 类型 | 备注 |
|------|------|------|
| 客户 | 查找 | 从 P&L/商机自动填充 |
| 地址 | 文本域 | 自动填充（如"Lot 20, Jalan Sultan, 80000 Johor"） |
| 联系人 | 文本输入 | 占位符"Input" |
| 电话 | 文本输入 | 占位符"Input" |
| 邮箱 | 文本输入 | 占位符"Input" |

### 3.3 财务摘要

| 指标 | 描述 |
|------|------|
| 不含税总额 | 税前基础价格 |
| 服务税 | 8% SST（马来西亚）— 自动计算 |
| 含税总额 | 不含税总额 + 服务税 |

### 3.4 行项目部分

- 节标题："Line Items"
- **全局服务**: 下拉（占位符"Select"）
- 表格列包含产品明细、数量、价格、税费计算

| 列 | 描述 |
|----|------|
| 复选框 | 行选择用于批量操作 |
| 序号（Seq） | 行号 |
| 不含服务税总额 | 基础价格，只读/计算 |
| 服务税编号 | 税率（如 0.08 表示 8%） |
| 服务税 | 税码标签选择器 |
| 含服务税总额 | 计算值：基础 + 税 |
| 总税额 | 计算的税额 |

> 💡 **提示**: 全局税务设置适用于所有行项目。

### 3.5 底部部分 — 富文本编辑器

![报价单条款与签名](../assets/quotation-002.jpg)

**条款与条件：**
- 富文本编辑器，带完整工具栏（撤销、重做、复制/粘贴、字号、段落格式、全屏）
- 包含 8 条编号项目：
  1. 交货时间（<6 天）
  2. 有效期
  3. 取消处罚（不退还押金）
  4. 不包含关税
  5. 价格变更权
  6. 保修（<xx>）
  7. 付款条件（<Payment Terms>）
  8. 保密条款（"Securemetric Technology Sdn Bhd"）
- 包含占位符：`<Validity>`、`<xx>`、`<Payment Terms>`

**制单人：** 只读 — "系统自动生成"

**批准人：** 空输入字段（审批后填充）

**接受说明：**
- 富文本编辑器，相同工具栏
- 内容："1. To accept this quotation, you can sign below with a company stamps by an authorized company"

**制单签名：** 文件上传（拖拽区域，jpg/gif/png）

**批准签名：** 文件上传（拖拽区域，jpg/gif/png）

**负责人：** 自动填充（如"admin0"）

**实体：** 标签选择器（如 SCMY）

**交易类别：** 下拉（如 PKI）

## 5. PDF 预览与导出

### 5.1 PDF 预览弹窗

- 标题："PDF Preview"
- 显示生成的报价单文档预览
- 财务摘要表格：
  - 不含服务税总额
  - 服务税 @ 8%
  - 总金额

### 5.2 PDF 内容

| 部分 | 内容 |
|------|------|
| 公司抬头 | "SECUREMETRIC TECHNOLOGY SDN. BHD. (759814-V)" |
| 客户信息 | TO、地址、联系人、电话、邮箱 |
| 行项目 | 产品明细含定价 |
| 条款与条件 | 8 条编号项目 |
| 签名区 | 制单人 + 批准人，含数字签名 |

### 5.3 导出流程

1. 在 PDF 预览弹窗中点击 **Export PDF** 按钮（蓝色主按钮）
2. 浏览器下载通知出现
3. 文件名格式："[商机名称] Quotation..."（如 708 KB）
4. 浏览器通知中显示"Done"状态

> ⚠️ **注意**: HTTP 环境可能显示"Insecure download blocked" — 下载请使用 HTTPS。

## 6. 审批流程

### 6.1 流程审批侧边栏

| 元素 | 描述 |
|------|------|
| 头部 | "Process Approvals"，带"Track"下拉 |
| 评论 | "Input Processing Comments"文本域 |
| 常用评论 | 快速插入标准评论 |
| 上传附件 | 支持文档 |
| 电子签名 | 数字签名预览，带"预览 | 删除" |
| 提交 | 大型蓝色提交按钮 |
| 展开审批选项 | 自定义审批链的可折叠部分 |

### 6.2 审批流程

```
草稿 → 提交 → MD/CM 审核 → 通过
                    ↓
                 拒绝 → 修改 → 重新提交
```

## 7. Excel 模板与配置

### 7.1 Excel 模板结构

公司使用离线 Excel 模板文件（`SMMY Quotation^J SO and PI Template.xlsm`），包含多个工作表：

| 工作表 | 描述 |
|--------|------|
| Quotation | 主报价单表单 |
| Sales Order | 从报价单自动生成的 SO |
| Proforma Invoice(MYR) | MYR 计价的 PI |
| Proforma Invoice(USD) | USD 计价的 PI |

### 7.2 模板功能

- **公司抬头**: Securemetric Technology Sdn Bhd (759614-V)
- **文档控制**: 表单编号、修订版、QP 编号
- **VBA 宏**: 模板包含用于自动化的宏
- **行限制警告**: "N 行超出模板限制，将被忽略"

### 7.3 Excel 编辑器弹窗

| 字段 | 描述 |
|------|------|
| 发货方式 | 如"Express Shipping" |
| 联系人姓名 | 如"David Smith" |
| 电话号码 | 联系电话 |
| 邮箱地址 | 联系邮箱 |
| 明细数据表格 | 行项目，列：序号、产品代码、产品名称、单位、折扣、总价 |

> ⚠️ **拼写错误**: Excel 编辑器列头显示 `fd_sm_prodcut_code`（"prodcut"而非"product"）。

## 8. 常见问题与注意事项

### 8.1 业务规则

1. 报价单从已批准的 P&L 分析生成 — 不能直接编辑
2. 版本对应：P&L V1 → 报价单 V1，P&L V2 → 报价单 V2
3. 每次版本变更都有完整的审计跟踪
4. 支持 8% SST（马来西亚）税务计算
5. 自动填充：客户、商机、币种、部门从父商机继承

### 8.2 数据流

```
商机 → P&L（已批准） → 报价单创建 → 保存（草稿） → 提交（审批） → 已批准报价单
```

### 8.3 已知问题

- `fd_sm_prodcut_code` — Excel 编辑器列头拼写错误
- "Insecure download blocked" — 浏览器可能阻止 HTTP 环境的下载
- 报价单模块在测试套件中尚无专用页面对象（测试覆盖率：0%）
