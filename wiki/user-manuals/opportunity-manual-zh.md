## 1. 模块概述

商机（Opportunity）是由 P&L（损益分析）驱动的已确认交易。P&L 是定价引擎，报价单是从已批准 P&L 生成的只读视图。

### 1.1 入口路径

- **侧边栏**: 导航至 **OPPORTUNITY（商机） → Opportunity**
- **从线索转化**: 线索 → 转化 → 步骤 2：商机

### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| 商机创建 | 从线索或直接创建已确认的交易 |
| 阶段管道 | 通过 5 个阶段跟踪交易进度 |
| P&L 管理 | 带审批流程的定价引擎 |
| 报价单生成 | 从已批准 P&L 自动生成 |
| 所有权转移 | 转移交易所有权，支持团队连续性选项 |
| 服务团队 | 管理团队成员和权限 |

## 3. 创建商机

### 3.1 入口

点击商机列表工具栏上的 **+ 创建** 按钮。

### 3.2 基本字段

| 字段 | 必填 | 类型 | 备注 |
|------|------|------|------|
| 商机名称 | 是 | 文本 | 交易名称 |
| 预计结束日期 | 否 | 日期选择器 | 格式：YYYY-MM-DD，然后回车 |
| 交易类别 | 否 | 级联选择器 | 与线索相同的选项（PKI、OTP、ADSS 等） |
| 销售管道 | 否 | 下拉 | 阶段选项动态加载 |
| 负责主体 | 否 | 关系弹窗 | 打开"选择记录"弹窗 |
| 产品描述 | 否 | 明细表 | 内联可编辑表格 |

## 5. 阶段管道

### 5.1 阶段定义

| 序号 | 阶段 | 赢率 | 类型 | 自动推进 |
|------|------|------|------|---------|
| 1 | 资格确认（Qualifying） | 25% | 开始 | 手动 |
| 2 | 方案/POC（Proposal/POC） | 50% | 进行中 | 手动 |
| 3 | 价格谈判（Price Negotiation） | 75% | 进行中 | 手动 |
| 4 | 赢单（Deal Won） | 100% | 结束 | — |
| 5 | 输单（Deal Lost） | 0% | 结束 | — |

### 5.2 阶段推进

- 水平步进器可视化，带编号圆圈
- **"推进到下一阶段"** 按钮（蓝色主按钮）
- 所有阶段需要手动推进

## 6. P&L 与报价流程

### 6.1 定价架构

```
商机 → P&L 创建 → P&L 审批 → 报价单生成
```

### 6.2 关键规则

1. **P&L 驱动定价**: P&L 是引擎，报价单只是"视图"
2. **版本锁定**: P&L V1 → 报价单 V1。价格变更需要创建新版本
3. **审批流程**: AM 提交 → MD/CM 审批。被拒绝的 P&L 必须修改后重新提交
4. **只有"活跃"的 P&L 版本** 才会包含在管道报告中

### 6.3 审批流程

```
AM 提交 P&L → MD/CM 审核 → 通过 → 生成报价单
                          ↓
                     拒绝 → AM 修改 → 重新提交
```

**审批记录表**: 开始节点 → 起草节点 → 审批 → 结束节点，含时间戳。

## 7. 所有权转移与服务团队

### 7.1 所有权转移逻辑

| 选项 | 描述 |
|------|------|
| 新负责人选择 | 用户选择器选择新负责人 |
| 原负责人选项 | 从团队中移除 / 降级为团队成员 |
| 权限 | 只读 / 读写 |
| 团队连续性 | 全部清除 / 保留现有 |

### 7.2 服务团队管理

- **添加组成员** 弹窗：成员选择、权限（只读/编辑和只读）、组特征
- 可以随时添加或移除团队成员

## 8. 常见问题与注意事项

### 8.1 任务创建

可从商机详情通过滑出抽屉创建任务：

| 字段 | 必填 |
|------|------|
| 任务标题 | 是 |
| 截止日期 | 是 |
| 负责人 | 否 |
| 执行人 | 是 |
| 优先级 | 是 |
| 关联类型 | 自动关联到商机 |
| 抄送收件人 | 否 |
| 描述 | 否 |
| 附件 | 否 |

### 8.2 业务规则

1. P&L 是定价引擎，报价单不能直接编辑
2. 只有活跃的 P&L 版本包含在管道报告中
3. 报告排序：实体 → 代表 → 日期
4. 商机编号自动生成：BSOP+YYYYMMDD+序列号

### 8.3 已知问题

- 审批流程测试覆盖率：0%
- "添加组成员"弹窗中"项目特征"字段 — 没有输入控件渲染
- 拼写错误：阶段模板中 "Oppourtunities" 拼写有误
- 阶段顺序在详情页和模板配置之间不一致
