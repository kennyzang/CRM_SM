## 1. 模块概述

**销售管道看板**（Pipeline Kanban）是一个单页仪表板，让每个团队成员都能一目了然地查看他们在整个销售周期中项目的进展状态。它以表格形式显示所有活跃项目，顶部设有阶段汇总栏。

### 1.1 入口

- **侧边栏**: 导航至 **CRM → Pipeline（管道）**

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| 阶段总览 | 查看 6 个管道阶段的项目数量和总金额 |
| 阶段筛选 | 点击阶段磁贴，将列表筛选至该阶段 |
| 时间/实体/代表筛选 | 按时间段、实体或销售代表筛选管道 |
| 交易导航 | 点击任意交易行，跳转至完整详情页 |
| 搜索 | 按项目名称、代表名或记录 ID 搜索 |

### 1.3 管道阶段

CRM 使用 **6 阶段管道**覆盖完整销售周期：

| 阶段 | 说明 |
|------|------|
| **LEAD（线索）** | 初步线索已录入 |
| **OPPORTUNITY（商机）** | 线索已合格，商机已创建 |
| **QUOTATION（报价）** | 已通过审批的 P&L 生成报价单 |
| **PO（采购订单）** | 已收到客户采购订单 |
| **SALES ORDER（销售订单）** | 已创建内部销售订单 |
| **PAYMENT（付款）** | 已收到付款 / 交易已关闭 |

## 2. 管道汇总栏

![销售管道看板仪表板](../assets/pipeline-kanban-001.png)

页面顶部水平排列六个阶段磁贴。每个磁贴显示：

- **阶段名称**（如 LEAD、OPPORTUNITY）
- **交易数量** — 该阶段的活跃项目数
- **管道金额** — 以分支机构默认货币（如 MYR）显示的总交易金额

### 示例

| 阶段 | 数量 | 金额 (MYR) |
|------|------|------------|
| LEAD | 3 | 102,915.13 |
| OPPORTUNITY | 0 | 0 |
| QUOTATION | 1 | 430,650 |
| PO | 1 | 430,650 |
| SALES ORDER | 2 | 861,300 |
| PAYMENT | 12 | 695,211 |

**交互**: 点击任意阶段磁贴，可将下方项目列表筛选至该阶段。出现 **Reset（重置）** 按钮可恢复完整视图。

## 3. 筛选栏

汇总栏下方设有筛选栏，可缩小管道视图范围：

| 筛选条件 | 类型 | 选项 |
|----------|------|------|
| **TIME（时间）** | 切换按钮 | This Year（今年）/ This Month（本月，默认）/ Custom（自定义） |
| **ENTITY（实体）** | 下拉菜单 | All（全部）/ 具体法人实体（如 SMMY、SCMY） |
| **REP（销售代表）** | 下拉菜单 | All（全部）/ 具体销售代表 |
| **Reset（重置）** | 按钮 | 清除所有筛选条件 |

筛选设置同时应用于汇总栏数值和下方交易表格。

## 4. 管道交易表格

### 4.1 汇总行

汇总行显示总数量和管道金额：

> 显示 **19** 笔交易 • 管道总额 **MYR 2,520,726.13**

### 4.2 表格列

| 列名 | 说明 |
|------|------|
| **Project（项目）** | 项目或客户名称 — 点击跳转至详情页 |
| **Amount（金额）** | 以分支机构默认货币显示的交易金额 |
| **Rep（销售代表）** | 指定销售代表（如 YCK） |
| **Pipeline Stage（管道阶段）** | 可视化圆点进度指示器 + 阶段名称标签 |

### 4.3 管道阶段圆点指示器

每笔交易的管道阶段以圆点进度条展示：

- **实心圆点**（●）— 已完成的阶段
- **高亮圆环**（◉）— 当前阶段
- **空心圆点**（○）— 未来阶段
- **阶段标签** — 末尾显示当前阶段名称（如 "Sales Order"、"Payment"）

这让您一眼就能看出每笔交易在 6 个阶段中的进展情况。

## 5. 导航与操作

### 5.1 搜索

页面右上角的搜索栏支持实时筛选：

- **搜索条件**: 项目名称、代表名或记录 ID
- **行为**: 输入时结果即时更新

### 5.2 跳转至详情页

点击表格中的任意项目行，可直接跳转至该交易的完整详情页。根据交易类型，将打开商机详情页、线索详情页或相应的记录页面。

### 5.3 重置筛选

点击阶段磁贴或应用筛选后，点击 **Reset（重置）** 可返回完整的、未筛选的管道视图。

## 6. 业务规则

1. **货币一致性**: 所有金额均以分支机构的默认货币显示，不进行货币转换或混合货币显示。
2. **阶段筛选**: 点击阶段磁贴可将列表筛选至该阶段。
3. **实时搜索**: 搜索结果随输入即时更新。
4. **时间筛选**: 支持今年、本月或自定义日期范围。
5. **实体/代表筛选**: 可将管道限定为特定法人实体或销售代表。

## 7. 常见问题

**Q: 为什么叫"看板"但看起来像表格？**
尽管名称为"看板"，管道视图使用的是表格布局而非卡片式看板。"看板"名称指的是可视化阶段跟踪的概念。

**Q: 我可以在这个页面上拖拽交易来切换阶段吗？**
不可以。阶段变更需要在单个交易的详情页使用"推进到下一阶段"按钮或通过工作流操作完成。

**Q: 为什么有些交易显示 MYR 而有些显示其他货币？**
所有金额都会转换为您所在分支机构的默认货币以保持一致性。管道仪表板上不会显示混合货币。

**Q: 点击项目行会怎样？**
您将跳转至该交易的完整详情页 — 可能是商机、线索或其他记录，具体取决于交易类型。

**Q: 如何只看我自己的交易？**
使用 **REP（销售代表）** 筛选下拉菜单选择您的姓名，或在搜索栏中搜索您的姓名。
