## 1. Module Overview

The **Payment Schedule** module tracks the accounts receivable (A/R) milestones for each Sales Order. Payment Schedule records are **automatically generated by the system** from the Sales Order — there is no manual "Create" form. Users interact with this module primarily to monitor collection progress, review receivable breakdowns, and trigger invoice applications.

Payment Schedule IDs follow the format: `PP` + `YYYYMMDD` + sequence number (e.g., `PP202604270002`).

### 1.1 Entry Points

| Entry Point | Path |
|-------------|------|
| Standalone list | Left sidebar → **REVENUE** → **Payment Schedule** | [Direct Link](http://172.18.114.231:8088/web/#/current/sys-modeling/app/km-ltc/listView/1i1ci5tf6w60w3982w3dlrp512h19a951tw1/1i1766s86w61w1qqwb76mdu5h0meq1vcelw1?type=list&navId=1hvp21k7lw4vw6h64w37pp9dm27vj66f3cw1){: target="_blank" rel="noopener"} |
| From Sales Order | Sales Order Details → **Payment Schedule** tab |

### 1.2 Core Functions

- Track receivable milestones (Down Payment, Progress Payment, Final Payment)
- Monitor completion percentage updated by the Project Manager (PM)
- Provide the Account Manager (AM) with signals to generate Invoice Applications
- Summarise invoiced, uninvoiced, and outstanding amounts per milestone
- Aggregate revenue data for reporting

| Column | Description |
|--------|-------------|
| Payment Schedule ID | System-generated reference number |

## 3. Viewing a Payment Schedule

Since Payment Schedules are system-generated, the primary user action is **viewing and monitoring**.

### 3.1 From the Sales Order

1. Open the relevant Sales Order.
2. Navigate to the **Payment Schedule** tab.
3. All milestone records for this SO are listed here, showing each payment type, amount, and status.

## 5. Business Rules & Workflow

### 5.1 Auto-generation from Sales Order

Payment Schedules are created **automatically** when a Sales Order is confirmed. The system generates one record per payment milestone defined in the SO's payment terms. Users do not fill a creation form.

### 5.2 Completion %

The **Completion %** field reflects the actual progress of project delivery or service fulfilment.

**How to change Completion %**:
1. Navigate to SO Details → Payment Schedule tab
2. Click on a Payment Schedule milestone to open the **Details drawer**
3. Click **"Change Completion %"** button (top-right of the drawer)
4. Set the new completion percentage and save

![Payment Schedule Progress](../../assets/payment-schedule-progress-001.png)

### 5.3 Receivable Calculation

Each Payment Schedule milestone's financial amounts are auto-calculated:

| Formula | Description |
|---------|-------------|
| Receivable Amount | Order Total × Receivable % (e.g., 37,709.74 × 20% = 7,541.95) |
| Uninvoiced Amount | Order Total − Invoiced Amount |
| Amount Uncollected | Order Total − Received Amount |

### 5.4 Payment Status Badge

| Status | Meaning |
|--------|---------|
| Pending | Invoice not yet issued |
| Invoiced | Invoice issued, payment not yet received |
| Partially Paid | Some payment received, balance outstanding |
| Paid | Full milestone amount collected |
