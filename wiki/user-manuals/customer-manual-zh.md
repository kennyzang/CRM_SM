## 1. 模块概述

**客户（Customer）** 模块是 Securemetric CRM 的核心实体，用于管理所有与公司有业务往来的组织或企业，分为**终端客户（End Customer）**（直接采购方）和**合作伙伴（Partner）**（经销商、分销商、系统集成商）。

所有下游业务单据——商机、报价单、销售订单、合同、收款——均与客户记录相关联。

### 1.1 入口

| 入口 | 路径 |
|------|------|
| 主入口 | 左侧导航 → **客户（Customer）** |
| 新建表单 | 左侧导航 → 客户 → **+ 新建**（或直接访问新建 URL） |

### 1.2 核心功能

- 维护所有业务账户（终端客户与合作伙伴）的主记录
- 追踪客户归属及协同跟进人（多位销售代表）
- 存储多国运营的地址信息（MY / VN / PH / ID）
- 作为整个销售流程的根节点锚点

## 2. 列表视图

客户列表展示当前登录用户有权查看的所有账户。主要列说明如下：

| 列名 | 说明 |
|------|------|
| 客户名称 | 主要标识，点击进入详情 |
| 客户类型 | 终端客户或合作伙伴 |
| 客户来源 | 客户获取渠道 |
| 法人注册码 | 唯一注册编号 |
| 电话 | 主要联系电话 |
| 负责人 | 指定的销售代表 |
| 最后修改时间 | 最近一次更新时间 |

### 筛选与搜索

- 使用顶部搜索栏按客户名称或法人注册码筛选。
- 使用筛选标签按客户类型、客户来源或负责人缩小范围。
- **我的客户**开关可将列表限定为当前用户负责或协同跟进的记录。

## 3. 创建客户

### 3.1 打开表单

在客户列表页点击 **+ 新建**，或直接访问新建 URL。

### 3.2 字段说明

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| 客户名称 | 是 | 文本输入 | 完整法定名称或商用名称 |
| 法人注册码 | 是 | 文本输入 | 系统全局唯一，不可重复 |
| 客户类型 | 否 | 级联下拉 | 终端客户 / 合作伙伴；影响子类型选项 |
| 客户来源 | 否 | 级联下拉 | 客户引入方式 |
| 电话 | 否 | 文本输入 | 主要联系电话 |
| 邮箱 | 否 | 文本输入 | 主要电子邮件地址 |
| 业务范围 | 否 | 多行文本 | 简要描述客户的业务领域 |
| 负责人 | 否 | 地址选择器 | 默认为当前登录用户 |
| 协同跟进人 | 否 | 多选用户选择器 | 可同时跟进该客户的其他销售代表 |

### 3.3 地址明细表

**地址**部分为**多行明细表**，而非单一输入框。每行代表一个业务地址。

| 子字段 | 必填 | 类型 | 说明 |
|--------|------|------|------|
| 国家 | 否 | 下拉 | MY / VN / PH / ID 等 |
| 州 / 省 | 否 | 文本输入 | 州或省名称 |
| 城市 | 否 | 文本输入 | 城市名称 |
| 邮政编码 | 否 | 文本输入 | 邮编 |
| 街道 | 否 | 文本输入 | 街道地址行 |
| 地址类型 | 否 | 下拉 | 如：账单地址、收货地址、注册地址 |

新增一行：点击地址明细表工具栏中的 **+ 插入**。
删除一行：点击对应行的 **删除**（垃圾桶图标）。

### 3.4 保存

点击顶部操作栏中的 **保存**。系统自动分配唯一客户 ID 并跳转至详情页。

## 4. 详情视图

客户详情页顶部显示主记录信息，下方为多个子选项卡。

### 4.1 头部信息

一览显示客户名称、客户类型、负责人及主要联系字段。

### 4.2 子选项卡

| 选项卡 | 内容 |
|--------|------|
| 基本信息 | 新建表单中的所有字段 |
| 联系人 | 关联的联系人 |
| 商机 | 与该客户关联的所有商机 |
| 报价单 | 为该客户创建的报价单 |
| 销售订单 | 已确认的销售订单 |
| 合同 | 已签署的合同 |
| 回款 | 已收到的付款记录 |
| 地址 | 地址明细表中的所有行 |
| 系统记录 | 创建与修改的审计日志 |

### 4.3 编辑

点击顶部操作栏的 **编辑** 进入编辑模式，修改后点击 **保存**。

## 5. 业务规则与流程

### 5.1 法人注册码唯一性

法人注册码字段强制执行**全系统唯一**约束。若保存时发现编码已被占用，系统将显示验证错误。请在新建前先行核查，避免重复创建。

### 5.2 非活跃客户归还公海池

**连续 60 天无任何活动**的客户将被系统自动归还至**公海池**，具体表现为：
- 清除负责人归属。
- 任何销售代表均可通过将自己设为负责人来认领该客户。
- 协同跟进人也同步清空。

请定期关注客户列表，防止客户被意外释放。

### 5.3 协同跟进人

**协同跟进人**功能允许多位销售代表与同一客户关联。所有协同跟进人均可：
- 查看客户记录及所有关联业务单据。
- 编辑客户信息（受角色权限限制）。
- 接收与该客户相关的通知。

### 5.4 客户类型：终端客户 vs 合作伙伴

| 类型 | 说明 |
|------|------|
| 终端客户（End Customer） | 直接使用或采购 Securemetric 产品/服务的组织 |
| 合作伙伴（Partner） | 代表 Securemetric 进行销售的经销商、分销商或系统集成商 |

客户类型驱动级联子类型选项。请在创建时选择正确类型，后期修改可能影响流水线报告。

### 5.5 多国分片

Securemetric CRM 支持跨国运营，覆盖**马来西亚（MY）**、**越南（VN）**、**菲律宾（PH）**和**印度尼西亚（ID）**。客户记录按国家分片：
- 报表可按国家筛选。
- 地址字段具备国家感知。
- 部分下拉选项因国家而异。

## 6. 常见问题与注意事项

**问：保存时提示"法人注册码已存在"，该怎么办？**
在客户列表中搜索该注册码，确认是否已有记录。若该记录属于其他负责人，请联系上级或通过公海池认领流程处理。切勿创建重复记录。

**问：我的客户从列表中消失了，在哪里？**
该客户可能因 60 天无活动而被归还至公海池。请进入公海池视图，通过客户名称搜索并重新认领。

**问：一个客户可以有多个负责人吗？**
**负责人**只能有一位，但可以添加多个**协同跟进人**。协同跟进人与负责人享有相同的查看和编辑权限。

**问：客户在多个城市有办公室，如何添加多个地址？**
在地址明细表中点击 **+ 插入**，为每个地址新增一行。每行可设置独立的地址类型（如账单地址、收货地址）。

**问：客户来源和客户类型有什么区别？**
- **客户来源**描述的是客户*如何获取*（如推荐、展会、陌拜）。
- **客户类型**描述的是客户*属于哪类*（终端客户或合作伙伴）。

**问：可以删除客户记录吗？**
客户删除受到限制。若客户已关联业务单据（商机、销售订单、合同等），则删除操作将被阻止。如需归档，请联系系统管理员。
