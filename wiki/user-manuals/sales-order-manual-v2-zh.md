## 1. 模块概述

销售订单（SO）模块用于管理已确认的客户订单。销售订单从已审批的报价单创建，商业详情自动填充。每个销售订单关联付款计划、交付记录和合同。

### 1.1 入口路径

- **侧边栏**: 导航至 **SALES ORDER（销售订单） → Sales Order**
- **从报价单**: 报价单详情 → Sales Order 标签 → 创建

### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| 报价转订单 | 从已审批报价单自动填充 |
| 付款计划 | 定义里程碑驱动的付款计划 |
| 收入追踪 | 追踪应收、已开票和已收款 |
| 审批流程 | 数字签名与多阶段审批 |
| 文档生成 | 导出销售订单为 PDF |

## 3. 创建销售订单

![销售订单创建页面](../assets/so-v2-002.jpg)

### 3.1 订单页眉字段

| 字段 | 必填 | 类型 | 描述 |
|------|------|------|------|
| 销售订单编号 | 自动 | 只读 | 提交时自动生成 |
| SO 编号 | 自动 | 只读 | 生成前显示 "-" |
| 客户采购单号 | 是 (*) | 文本 | 必填的客户采购单号 |
| 销售代表 | 是 | 用户查找 | 如 CK |
| 采购单日期 | 是 | 日期选择器 | 客户采购单日期 |
| 部门 | 自动 | 只读 | 从实体自动填充 |
| 收件人 | 否 | 查找 | 收件联系人 |
| 地址详情 | 是 | 查找 | 打开地址选择 |
| 报价单 | 是 | 查找 | 来源报价单 |
| 商机 | 自动 | 只读 | 父级商机 |
| 货币 | 自动 | 只读 | 从报价单继承 |
| 订单日期 | 是 (*) | 日期选择器 | 默认为当天 |
| 实体 | 是 | 标签 | 如 SMMY |
| 实体代码 | 自动 | 只读 | 从实体自动填充 |
| 条款 | 否 | 多行文本 | 付款/交付条款 |
| 交付日期 | 否 | 日期选择器 | 预期交付日期 |
| 运输方式 | 否 | 下拉 | 运输方式 |
| 项目经理 | 否 | 用户查找 | 指定的项目经理 |
| 订单金额 | 自动 | 只读 | 从行项目自动计算 |
| 交易类别 | 是 | 下拉 | 如 ADSS |

### 3.2 账单收件方（客户）部分

| 字段 | 描述 |
|------|------|
| 客户名称 | 从报价单自动填充 |
| 地址 | 客户账单地址 |
| 收件人姓名 | 联系人姓名 |
| 电话 | 客户电话 |
| 邮箱 | 客户邮箱 |

### 3.3 产品列表

产品从报价单自动填充：

| 列名 | 描述 |
|------|------|
| 服务周期 | 如 "Year1" |
| 产品 | 产品名称 |
| 类型 | 软件 / 硬件 / 服务 |
| 数量 | 从报价单 |
| 单价 | 从报价单 |
| 总额 | 自动计算 |

**产品合计**: 所有行项目总和（如 25,277.40）

## 6. 收入拆分逻辑

产品信息字段支持按里程碑对产品类别进行收入拆分：

![收入拆分](../assets/so-v2-006.jpg)

**示例**:
| 里程碑 | 付款类型 | 产品信息 |
|--------|---------|---------|
| 安装 | 预付款 | 软件 10% 硬件 20% |
| 最终交付 | 尾款 | 软件 90% 硬件 80% |

每个产品类别在所有里程碑中的百分比总和必须为 100%。

![审批侧边栏](../assets/so-v2-007.jpg)

### 7.1 审批流程侧边栏

- **Track（追踪）**: 选择工作流操作

## 8. 常见问题与注意事项

### 8.1 如何创建销售订单？

销售订单从已审批的报价单创建。当您从报价单点击创建时，商业详情会自动填充。

### 8.2 预付款和尾款有什么区别？

- **预付款**: 初始付款（通常是较小比例）
- **尾款**: 交付/完成后的剩余余额

### 8.3 收入拆分是如何工作的？

使用"按产品"里程碑类型时，系统会按产品类别（软件/硬件）在所有付款里程碑之间拆分收入。每个类别的百分比总和必须为 100%。

### 8.4 可以添加自定义付款里程碑吗？

可以，使用"+ Add rows"按钮或"Insert"行操作来添加自定义里程碑。
