## 1. 模块概述

**查重（Duplicate Check）** 模块允许您在创建新客户或联系人之前，搜索系统中是否已存在相同或相似记录。这有助于防止重复录入，确保 CRM 数据质量。此外，本模块还提供客户和联系人记录的常用操作入口，包括导入、导出、更换负责人和工作交接。

### 1.1 入口

- **侧边栏**：左侧导航 → **CRM → DUPLICATE CHECK（查重）** | [直达链接](http://172.18.114.231:8088/web/#/current/sys-modeling/app/km-ltc/listView/1i2b2u2how6aw3k7dw1a3anjl3jnug8m31w1/undefined?navId=1hvp21k7lw4vw6h64w37pp9dm27vj66f3cw1){: target="_blank" rel="noopener"}

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| 跨实体搜索 | 一次搜索同时查询联系人和客户 |
| 模糊匹配 | 部分文本匹配，搜索结果高亮显示 |
| 分标签结果 | 按实体类型分类显示，带数量徽章 |
| 快速导航 | 点击结果可查看或编辑完整记录 |
| 数据导入 | 通过 Excel 模板批量导入客户或联系人数据 |
| 数据导出 | 将记录列表导出为 Excel 文件 |
| 更换负责人 | 将单条或多条记录的负责人转移给其他用户 |
| 工作交接 | 将某位用户名下的所有记录批量转交给接收人 |

## 2. 搜索界面

![查重搜索界面——搜索栏与搜索结果分类展示](../../assets/duplicate-check-001.png)

### 2.1 搜索栏

搜索栏是查找潜在重复项的主要输入：

- **单个输入框** — 在此输入搜索关键词
- **搜索目标**：名称、手机、邮箱、注册代码（Legal ID）
- **清除按钮**（x）— 清除当前搜索文本
- **搜索按钮**（放大镜）— 执行搜索

### 2.2 搜索步骤

1. 在搜索栏中输入关键词（例如 "Enterprise"、电话号码或邮箱地址）
2. 点击 **搜索** 按钮或按 **Enter** 键
3. 结果将显示在下方，同时展示来自联系人和客户的匹配结果

## 3. 搜索结果

### 3.1 结果汇总栏

搜索后，汇总栏显示总匹配数：

- **找到 X 条记录** — 所有实体的总匹配数
- **Y 个联系人** — 联系人匹配数量
- **Z 个客户** — 客户匹配数量

### 3.2 结果标签页

结果分为两个标签页：

- **Customers（客户）**（Z 条）— 匹配的客户记录（默认标签）
- **Contacts（联系人）**（Y 条）— 匹配的联系人记录

### 3.3 结果表格

| 列名 | 说明 |
|------|------|
| **No.（序号）** | 行号 |
| **Name（名称）** | 客户或联系人名称 — 匹配文本以 **黄色高亮** 显示 |
| **Owner（负责人）** | 记录负责人（如 Soo、CK、Alan） |
| **Entity（实体）** | 法人实体代码（如 SMMY、SCMY、SMPH、PTSK） |
| **Legal ID（法定 ID）** | 注册代码或唯一标识符 |

### 3.4 模糊匹配高亮

当您搜索一个关键词（如 "enter"）时，系统会执行模糊匹配并**在结果名称中黄色高亮匹配文本**：

- "Unified Data **Enter**prises (M) Sdn Bhd"
- "Elite **Enter**prise Solutions Sendirian Berhad"
- "Elite Technology **Enter**prises (M) Sdn Bhd"
