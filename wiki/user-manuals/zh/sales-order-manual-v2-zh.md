## 1. 模块概述

销售订单（SO）模块用于管理已确认的客户订单。销售订单从已审批的报价单创建，商业详情自动填充。每个销售订单关联付款计划、交付记录和合同。

### 1.1 入口路径

- **侧边栏**: 导航至 **SALES ORDER（销售订单） → Sales Order** | [直达链接](http://172.18.114.231:8088/web/#/current/sys-modeling/app/km-ltc/listView/1i1ci4gjnw60w3973w1gr0fs43klt2f92uw1/1i16o9mkuw60w6fgw1f9etod28hn26g1q3w1?type=list&navId=1hvp21k7lw4vw6h64w37pp9dm27vj66f3cw1){: target="_blank" rel="noopener"}
- **从报价单**: 报价单详情 → Sales Order 标签 → 创建

### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| 报价转订单 | 从已审批报价单自动填充 |
| 付款计划 | 定义里程碑驱动的付款计划 |
| 收入追踪 | 追踪应收、已开票和已收款 |

## 3. 创建销售订单

![销售订单创建页面](../../assets/so-v2-002.png)

### 3.1 订单页眉字段

| 字段 | 必填 | 类型 | 描述 |
|------|------|------|------|
| 销售订单编号 | 自动 | 只读 | 提交时自动生成 |
| SO 编号 | 自动 | 只读 | 生成前显示 "-" |
| 客户采购单号 | 是 (*) | 文本 | 必填的客户采购单号 |
| 销售代表 | 是 | 用户查找 | 如 CK |
| 采购单日期 | 是 | 日期选择器 | 客户采购单日期 |
| 部门 | 自动 | 只读 | 从实体自动填充 |
| 收件人 | 否 | 查找 | 收件联系人 |
| 地址详情 | 是 | 查找 | 打开地址选择 |
| 报价单 | 是 | 查找 | 来源报价单 |
| 商机 | 自动 | 只读 | 父级商机 |
| 货币 | 自动 | 只读 | 从报价单继承 |
| 订单日期 | 是 (*) | 日期选择器 | 默认为当天 |
| 实体 | 是 | 标签 | 如 SMMY |
| 实体代码 | 自动 | 只读 | 从实体自动填充 |
| 条款 | 否 | 多行文本 | 付款/交付条款 |
| 交付日期 | 否 | 日期选择器 | 预期交付日期 |
| 运输方式 | 否 | 下拉 | 运输方式 |
| 项目经理 | 否 | 用户查找 | 指定的项目经理 |
| 订单金额 | 自动 | 只读 | 从行项目自动计算 |
| 交易类别 | 是 | 下拉 | 如 ADSS |

### 3.2 客户信息

客户名称从报价单自动填充，其余字段（地址、收件人姓名、电话、邮箱）一同带入。

### 3.3 产品列表

产品从报价单自动填充：

| 列名 | 描述 |
|------|------|
| 服务周期 | 如 "Year1" |
| 产品 | 产品名称 |
| 类型 | 软件 / 硬件 / 服务 |
| 数量 | 从报价单 |
| 单价 | 从报价单 |
| 总额 | 自动计算 |

**产品合计**: 所有行项目总和（如 25,277.40）

## 5. 付款计划管理

### 5.1 嵌入式付款计划（创建销售订单时）

付款计划部分以可折叠面板形式嵌入在销售订单创建页面中。

**里程碑类型**: 下拉菜单 — 两种选项：
- **"按百分比"（By Percentage）** — 将付款里程碑定义为百分比（如 20% + 80% = 100%）
- **"按产品"（By Products）** — 按产品类别跨里程碑拆分收入

![按百分比里程碑](../../assets/so-milestone-by-percentage-001.png)

**如何设置"按百分比"里程碑**：
1. 设置里程碑类型 = **"按百分比"**
2. 添加里程碑行：名称、应收百分比
3. 验证百分比总和为 **100%**（系统会验证）
4. **应收金额** 自动计算：产品总和 × 应收百分比

![按产品里程碑](../../assets/so-milestone-by-product-001.png)

> 💡 **提示**：按产品新建的里程碑，没有应收比例和金额。开票结束后，系统会根据开票金额自动更新应收比例和金额。

**列**:
| 列名 | 描述 |
|------|------|
| 序号 | 行号 |
| 里程碑名称 | 如 "安装" |
| 付款类型 | 预付款 / 进度款 / 尾款 |
| 工作内容 | 工作描述 |
| 合同条款 | 该里程碑的合同条款 |
| 产品信息 | 按产品类别的收入拆分 |
| 操作 | 插入 | 复制 | 删除 |
