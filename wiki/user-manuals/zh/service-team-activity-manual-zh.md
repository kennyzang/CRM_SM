## 1. 模块概述

**服务团队（Service Team）** 和 **活动日志（Activity Log）** 是贯穿 CRM 所有客户相关记录的两个核心功能，适用于线索（Lead）、联系人（Contact）、客户（Customer）和商机（Opportunity）。

- **服务团队** — 控制哪些用户可以**查看和编辑**某条记录。若用户不在记录的服务团队中，则无法访问该记录。
- **活动日志** — 记录每次销售互动（电话、拜访、会议等），形成完整的沟通历史。

### 1.1 入口路径

| 功能 | 路径 |
|------|------|
| 服务团队 / 活动日志 | 任意详情页（线索/联系人/客户/商机）→ 右侧边栏 |
| 活动日志主视图 | 左侧导航 → **ACTIVITY → Activity Log** | [直达链接](http://172.18.114.231:8088/web/#/current/sys-modeling/app/km-ltc/listView/1i1r42sh5w66w24q5wnqffnh3mmfg00jmgw1/1i3cio88kw6ow25o9w3ecc0ud37mbv5810w1?type=list&navId=1hvp21k7lw4vw6h64w37pp9dm27vj66f3cw1){: target="_blank" rel="noopener"} |

### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| 服务团队管理 | 为每条 CRM 记录指定有权访问的用户及权限级别 |
| 活动日志记录 | 记录电话、拜访、会议等客户互动，形成时间线 |
| 销售记录（联系人） | 联系人实体中的活动日志，功能相同，命名不同 |
| 待办消息 | 任务提醒、跟进超时等通知，集中显示在待办面板 |

## 2. 服务团队

### 2.1 什么是服务团队？

服务团队是有权访问某条特定记录的 CRM 用户列表。每条记录（线索、联系人、客户、商机）均维护各自独立的服务团队。加入某实体的团队**不会**自动授予访问相关实体的权限。

> "服务团队是指有权查看和编辑该详情页信息的人员。"

### 2.2 服务团队成员属性

| 属性 | 选项 | 默认值 | 说明 |
|------|------|--------|------|
| 成员 | 组织内任意用户 | — | 通过用户选择器选取 |
| 权限 | 只读 / 读写 | 读写 | 控制成员是否可编辑 |
| 团队角色 | 普通成员 | 普通成员 | 内部团队结构标签 |
| 项目角色 | 客户经理 | （未勾选） | 若该人员为客户负责人，可勾选 |

### 2.3 如何添加团队成员

1. 打开任意详情页（线索、联系人、客户或商机）。
2. 在右侧边栏找到**服务团队**面板。
3. 点击 **+ 添加**（若已有成员，则点击 **+ 继续添加**）。
4. 在**添加团队成员**弹窗中：
   - **成员**（\*）：选择要添加的用户。
   - **权限**（\*）：选择**只读**或**读写**。
   - **团队角色**：勾选**普通成员**（默认）。
   - **项目角色**：如适用，勾选**客户经理**。
5. 点击**确认**。

![添加团队成员弹窗——成员、权限、团队角色与项目角色字段](../../assets/service-team-002.png)

新成员立即出现在服务团队列表中，并可按其权限级别访问该记录。

### 2.4 如何移除团队成员

1. 打开详情页。
2. 在服务团队面板中找到该成员。
3. 点击其姓名旁的**删除**（垃圾桶）图标。
4. 确认移除。

该用户立即失去对该记录的访问权限。

![移除团队成员——点击垃圾桶图标确认移除](../../assets/service-team-003.png)

### 2.5 各实体中服务团队的位置

| 实体 | 位置 |
|------|------|
| 线索 | 线索详情页右侧边栏 |
| 联系人 | 联系人详情页右侧边栏 |
| 客户 | 客户详情页右侧边栏 |
| 商机 | 商机详情页右侧边栏 |

![服务团队面板——右侧边栏展示团队成员与权限级别](../../assets/service-team-001.jpg)


不在服务团队中的用户对该记录**无任何访问权限**。只读权限可查看不可编辑；读写权限可查看和编辑。

## 3. 活动日志与销售记录

### 3.1 什么是活动日志？

活动日志记录与某条记录相关的所有销售互动——电话沟通、上门拜访、会议洽谈等，形成可查阅的完整沟通时间线。

**命名说明**：该功能在线索、客户、商机中称为**活动日志（Activity Log）**，在联系人实体中称为**销售记录（Sales Record）**，但功能完全相同。

| 实体 | 选项卡 / 面板名称 |
|------|------------------|
| 线索 | 活动日志 |
| 联系人 | 销售记录 |
| 客户 | 活动日志 |
| 商机 | 活动日志 |

### 3.2 销售记录入口

活动日志和销售记录可从以下多个位置访问：

| 入口 | 路径 | 适用场景 |
|------|------|---------|
| 线索详情页 | 右侧边栏 → **活动日志** | 查看/记录与某条线索相关的互动 |
| 联系人详情页 | 右侧边栏 → **销售记录** | 查看/记录与某位联系人的互动（命名不同，功能相同） |
| 客户详情页 | 右侧边栏 → **活动日志** | 查看/记录与某个客户相关的互动 |
| 商机详情页 | 右侧边栏 → **活动日志** | 查看/记录与某个商机推进相关的互动 |
| ACTIVITY 主模块 | 左侧导航 → **ACTIVITY → Activity Log** | 汇总视图，查看当前用户所有相关记录的活动日志 |

> **提示**：从 ACTIVITY 主模块进入时，可按实体类型、时间范围和负责人进行筛选，适合管理层进行跨记录的活动概览。

### 3.3 如何记录活动

1. 打开任意详情页（线索、联系人、客户或商机）。
2. 在右侧边栏找到**活动日志**（或**销售记录**）面板。
3. 点击**新建记录**（或**记录活动**）。
4. 填写活动表单：

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| 活动类型 | 是 | 下拉选择 | 例如"电话沟通"、"拜访"、"会议" |
| 联系人 | 是 | 关联查找 | 此次互动涉及的联系人 |
| 我方参与人 | 是 | 用户查找 | 自动填充为当前用户；可添加其他参与者 |
| 关联业务 | 否（自动） | 只读 | 自动填充为父记录名称 |
| 讨论详情 | 否 | 多行文本 | 互动备注（最多 1000 字） |
| 附件 | 否 | 文件上传 | 支持文件（如会议纪要、通话记录） |

5. 点击**提交**。

![新建销售记录表单——活动类型、联系人与讨论详情字段](../../assets/service-team-004.png)

日志条目立即显示在活动日志时间线上，包含时间戳、您的姓名和活动类型。

## 4. 待办消息与跟进超时

### 4.1 待办消息（To-Do Messages）

**待办消息**集中在 CRM 顶部导航栏的铃铛图标（🔔）和**待办事项（To-Do）**面板中。以下操作会自动生成待办消息：

| 触发场景 | 消息内容 |
|---------|---------|
| 任务被分配给您 | "您有一条新任务：[任务标题]，截止 [日期]" |
| 任务提醒触发 | "任务 [标题] 将于 [时间] 到期" |
| 跟进超时告警 | "[线索/商机名称] 已超过 N 天未跟进，请及时处理" |
| 被@提及在活动日志中 | "您在 [记录名称] 的活动日志中被提及" |

点击待办消息可直接跳转至对应记录或任务。

### 4.2 跟进超时（Follow-up Timeout）

**跟进超时**是指某条线索或商机在超过管理员配置的天数内没有任何活动日志记录时，系统自动触发的预警机制。

**工作原理**：

```
记录上次活动日志日期
        ↓
系统每日检查各记录的最后活动日期
        ↓
超过阈值天数（如 7 天）未记录活动
        ↓
生成"跟进超时"待办消息 → 推送给记录负责人（及管理员）
        ↓
负责人在对应记录上记录一条新活动日志
        ↓
待办消息自动关闭，计时器重置
```

**超时告警参数**（由管理员在系统后台配置）：

| 参数 | 说明 |
|------|------|
| 超时天数 | 多少天未跟进触发告警（如 7 天、14 天） |
| 适用实体 | 线索 / 商机 / 客户（可分别配置） |
| 通知对象 | 记录负责人 / 负责人的直属上级 |
| 通知方式 | 待办事项 + 邮件（可选） |

**处理超时告警**：进入对应线索或商机详情页，在活动日志中记录一次新的互动（如"电话跟进：确认采购意向"），系统自动关闭该条超时告警并重置计时器。

## 5. 线索转化时的数据迁移

### 5.1 概述

将线索转化为联系人、客户和商机时，系统会在转化向导第二步提供**数据迁移（Carry Over Information）**选项，用于控制线索的服务团队成员和活动日志是否复制到新建记录中。

### 5.2 复制团队至

| 勾选项 | 效果 | 默认 |
|--------|------|------|
| 客户 | 将线索的服务团队复制到新建客户的服务团队 | 已勾选 |
| 联系人 | 将线索的服务团队复制到新建联系人的服务团队 | 已勾选 |
| 商机 | 将线索的服务团队复制到新建商机的服务团队 | 已勾选 |

### 5.3 复制活动至

| 勾选项 | 效果 | 默认 |
|--------|------|------|
| 客户 | 将线索的活动日志复制到客户的活动日志 | 已勾选 |
| 联系人 | 将线索的活动日志复制到联系人的销售记录 | 已勾选 |
| 商机 | 将线索的活动日志复制到商机的活动日志 | 已勾选 |

**最佳实践**：保持所有勾选框为默认选中状态，确保转化后每条相关记录都能查看完整的历史记录。

![线索转化数据迁移——复制团队与复制活动的勾选框](../../assets/service-team-005.png)

### 5.4 迁移内容示例

```
线索
  服务团队：[Alice, Bob] → 复制至客户、联系人、商机
  活动日志：["2026-06-01 电话：讨论了需求"]
            → 复制至客户、联系人、商机
```

## 6. 业务规则与流程

### 6.1 角色权限

| 权限项 | 说明 | 普通员工 | 销售管理员 | 管理员 |
|--------|------|:-------:|:--------:|:-----:|
| 查看活动日志 | 查看所在服务团队记录的活动日志 | ✓ | ✓ | ✓ |
| 记录活动日志 | 在有读写权限的记录上添加活动日志 | ✓ | ✓ | ✓ |
| 删除活动日志 | 删除自己创建的活动日志条目 | ✓(自己) | ✓ | ✓ |
| 查看服务团队 | 查看记录的服务团队成员列表 | ✓ | ✓ | ✓ |
| 管理服务团队 | 添加/移除/修改服务团队成员权限 | ✓(负责人) | ✓ | ✓ |

> 实际权限分配以系统后台配置为准；如需调整，请联系系统管理员。

### 6.2 服务团队按实体独立配置

加入客户的服务团队**不会**自动授予访问该客户旗下商机的权限。每个商机（以及线索、联系人）都有独立的服务团队，必须单独配置，或通过线索转化数据迁移来填充。

### 6.3 负责人与服务团队

记录的**负责人（Owner）**是对该记录负主要责任的人员。负责人通常会被自动加入服务团队，但请务必确认——尤其是在编辑或重新分配归属后。

### 6.4 活动日志最佳实践

- 每次重要的客户互动后应及时记录，保持历史记录的准确性。
- 在**讨论详情**字段中记录关键结论、后续行动或承诺事项。
- 通过**附件**字段上传会议纪要或通话记录，留存完整文档。

## 7. 常见问题与注意事项

**问：列表中可以看到某条线索，但无法打开，原因是什么？**
您未被加入该线索的服务团队。请联系该记录的负责人或管理员，申请至少添加为只读权限成员。

**问：我已加入客户的服务团队，但看不到该客户的商机，为什么？**
服务团队按实体独立配置。您需要由商机的负责人或管理员单独将您加入商机的服务团队。

**问：只读权限能记录活动日志吗？**
不能。记录活动日志属于编辑操作，需要读写权限。

**问：联系人里的"销售记录"和其他地方的"活动日志"是同一个功能吗？**
是的，功能完全相同，只是联系人实体使用了不同的名称。字段和操作流程均一致。

**问：服务团队成员数量有限制吗？**
目前无明确限制。建议添加所有相关人员，同时保持列表简洁，避免权责不清。

**问：添加成员后，可以修改其权限吗？**
可以。在服务团队面板中点击该成员行的**编辑**图标，修改权限设置即可。

**问：跟进超时告警已出现，但我已有跟进记录，为什么没消失？**
跟进超时计时器基于活动日志记录日期重置。请确认您已在该线索或商机的**活动日志**面板中提交了新的活动条目（仅查看记录不会重置）。如问题仍然存在，请联系管理员核查超时规则配置。
