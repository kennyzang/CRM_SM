## 1. 模块概述

报价单（Quotation）是从已批准 P&L 分析生成的正式销售文档。报价单遵循"锁定对"定价架构，并进入审批流程。

### 1.1 核心特征

| 特征 | 描述 |
|------|------|
| P&L 驱动 | 从已批准的 P&L 分析生成 |
| 版本锁定 | P&L V1 → 报价单 V1，P&L V2 → 报价单 V2 |
| 自动填充 | 客户、商机、币种、部门从父级继承 |
| 需要审批 | 定稿前进入审批流程 |

### 1.2 入口路径

- **侧边栏**: OPPORTUNITY → Quotation | [直达链接](http://172.18.114.231:8088/web/#/current/sys-modeling/app/km-ltc/listView/1i0kj6488w5pwln4w35a08362ga8q8b3q6w1/1i20q3rcsw6cw51iw6jmt7028o9aka2etcw1?type=list&navId=1hvp21k7lw4vw6h64w37pp9dm27vj66f3cw1){: target="_blank" rel="noopener"}

## 3. 创建报价单

### 3.1 入口

通过侧边栏 OPPORTUNITY → Quotation 进入列表，点击 **"+ Create Quotation"** 打开报价单创建面板。

![报价单创建面板](../../assets/quotation-001.png)

### 3.2 头部信息

| 字段 | 必填 | 类型 | 备注 |
|------|------|------|------|
| 报价单标题 | 是 | 文本 + 自动补全 | 自动补全建议已有名称（如"...Quotation2"） |
| P&L | 是 | 查找 | P&L ID（如 2026052700008） |
| 币种 | 自动 | 文本 | 自动填充"MYR" |
| 部门 | 否 | 标签输入 | 如"SMMY"，可点击 'x' 移除 |
| 商机 | 自动 | 只读 | 父商机名称 |
| 发货方式 | 否 | 下拉 | 标准/快递/隔夜/优先/经济/空运/陆运 |
| 付款条件 | 否 | 文本 | 如"Refer to T&C" |
| 销售代表 | 自动 | 文本 | 自动填充（如"YCK"） |
| 报价日期 | 自动 | 日期选择器 | 自动设为当前日期 |
| 联系人（Attn） | 否 | 下拉 | 占位符"Select" |
| P&L ID | 自动 | 只读 | 与 P&L 查找值相同 |
| 地址 | 自动 | 文本域 | 从客户自动填充 |

### 3.3 客户信息（TO）部分

| 字段 | 类型 | 备注 |
|------|------|------|
| 客户 | 查找 | 从 P&L/商机自动填充 |
| 地址 | 文本域 | 自动填充（如"Lot 20, Jalan Sultan, 80000 Johor"） |
| 联系人 | 文本输入 | 占位符"Input" |
| 电话 | 文本输入 | 占位符"Input" |
| 邮箱 | 文本输入 | 占位符"Input" |

### 3.4 财务摘要

| 指标 | 描述 |
|------|------|
| 不含税总额 | 税前基础价格 |
| 服务税 | 8% SST（马来西亚）— 自动计算 |
| 含税总额 | 不含税总额 + 服务税 |

### 3.5 行项目部分

- 节标题："Line Items"
- **全局服务**: 下拉（占位符"Select"）
- 表格列包含产品明细、数量、价格、税费计算

| 列 | 描述 |
|----|------|
| 序号（Seq） | 行号 |
| 不含服务税总额 | 基础价格，只读/计算 |
| 服务税编号 | 税率（如 0.08 表示 8%） |
| 服务税 | 税码标签选择器 |
| 含服务税总额 | 计算值：基础 + 税 |
| 总税额 | 计算的税额 |

> 💡 **提示**: 全局税务设置适用于所有行项目。

![报价单创建 - 服务税设置](../../assets/quotation-tax-001.png)

### 3.6 底部部分 — 富文本编辑器

![报价单条款与签名](../../assets/quotation-002.png)

**条款与条件：**
- 富文本编辑器，带完整工具栏（撤销、重做、复制/粘贴、字号、段落格式、全屏）
- 包含 8 条编号项目：
  1. 交货时间（<6 天）
  2. 有效期
  3. 取消处罚（不退还押金）
  4. 不包含关税
  5. 价格变更权
  6. 保修（<xx>）
  7. 付款条件（<Payment Terms>）
  8. 保密条款（"Securemetric Technology Sdn Bhd"）
- 包含占位符：`<Validity>`、`<xx>`、`<Payment Terms>`

**制单人：** 只读 — "系统自动生成"

**批准人：** 空输入字段（审批后填充）

**接受说明：**
- 富文本编辑器，相同工具栏
- 内容："1. To accept this quotation, you can sign below with a company stamps by an authorized company"

**制单签名：** 文件上传（拖拽区域，jpg/gif/png）

**批准签名：** 文件上传（拖拽区域，jpg/gif/png）

**负责人：** 自动填充（如"admin0"）

**实体：** 标签选择器（如 SCMY）

**交易类别：** 下拉（如 PKI）

### 5.2 PDF 内容

| 部分 | 内容 |
|------|------|
| 公司抬头 | "SECUREMETRIC TECHNOLOGY SDN. BHD. (759814-V)" |

### 5.3 导出流程

1. 在 PDF 预览弹窗中点击 **Export PDF** 按钮（蓝色主按钮）
2. 浏览器下载通知出现
3. 文件名格式："[商机名称] Quotation..."（如 708 KB）
4. 浏览器通知中显示"Done"状态

## 7. 常见问题与注意事项

### 7.1 角色权限

| 角色权限 | 说明 | 一般员工 | 销售管理员 | 管理员 |
|---------|-----|:-------:|:--------:|:-----:|
| 报价单-新建 | 创建报价单记录 | ✓ | ✓ | ✓ |
| 报价单-编辑 | 编辑草稿状态的报价单 | ✓ | ✓ | ✓ |
| 报价单-删除 | 删除报价单记录 | — | ✓ | ✓ |
| 报价单-导出 | 导出报价单 PDF | ✓ | ✓ | ✓ |
| 报价单-提交审批 | 提交报价单进入审批流程 | ✓ | ✓ | ✓ |
| 报价单-审批 | 审批或拒绝提交的报价单 | — | — | ✓（MD/CM）|
| 报价单-查看全部 | 查看非本人负责的报价单 | — | ✓ | ✓ |

> 实际权限以系统后台配置为准。报价单审批权限（MD/CM）由管理员在流程设计中指定。

### 7.2 业务规则

1. 报价单从已批准的 P&L 分析生成 — 不能直接编辑
2. 版本对应：P&L V1 → 报价单 V1，P&L V2 → 报价单 V2
3. 每次版本变更都有完整的审计跟踪

### 7.3 数据流

```
P&L（已批准） → 报价单创建 → 保存（草稿） → 提交（审批） → 已批准报价单
```
