## 1. 模块概述

**付款计划（Payment Schedule）** 模块用于追踪每个销售订单的应收账款（A/R）里程碑。付款计划记录由系统从销售订单**自动生成**，没有手动"新建"表单。用户主要通过该模块监控回款进度、查看应收账款明细，以及触发开票申请。

付款计划编号格式：`PP` + `YYYYMMDD` + 序号（例如：`PP202604270002`）。

### 1.1 入口

| 入口 | 路径 |
|------|------|
| 独立列表 | 左侧导航 → **收入（REVENUE）** → **付款计划（Payment Schedule）** |
| 从销售订单进入 | 销售订单详情 → **付款计划** 选项卡 |

### 1.2 核心功能

- 追踪应收款里程碑（首付款、进度款、尾款）
- 监控由项目经理（PM）更新的完成度百分比
- 为客户经理（AM）提供生成开票申请的触发信号
- 汇总每个里程碑的已开票、未开票及未收款金额
- 为报表提供收入数据汇总

## 3. 查看付款计划

由于付款计划由系统自动生成，用户的主要操作是**查看和监控**。

### 3.1 从销售订单进入

1. 打开相关销售订单。
2. 切换至 **付款计划** 选项卡。
3. 该销售订单的所有里程碑记录在此列出，显示各付款类型、金额和状态。

### 3.2 从独立列表进入

1. 进入左侧导航 → **收入（REVENUE）** → **付款计划（Payment Schedule）**。
2. 使用搜索栏按销售订单编号、客户或付款计划编号查找。
3. 点击某行进入该里程碑的详情视图。

## 5. 业务规则与流程

### 5.1 从销售订单自动生成

付款计划在销售订单确认时由系统**自动生成**，每个在销售订单付款条款中定义的里程碑对应生成一条记录，无需用户手动填写创建表单。

### 5.2 典型付款结构（50/50 分账）

Securemetric 最常见的付款结构为**五五分账**：

| 里程碑 | 付款类型 | 占销售订单金额比例 |
|--------|---------|-----------------|
| PO/合同签署时 | 首付款（Down Payment） | 50% |
| 交付/项目完成时 | 进度款（Progress Payment）或尾款（Final Payment） | 50% |

部分项目根据合同条款采用三段式分账（如 30% 首付 / 40% 进度款 / 30% 尾款）。

### 5.3 完成度 % 由 PM 更新

**完成度 %** 字段由**项目经理（PM）** 而非客户经理维护，反映项目交付或服务履行的实际进度：
- 0% = 项目未开始
- 50% = 达到中间里程碑
- 100% = 项目/服务全部交付完成

### 5.4 完成度达 100% 时触发开票申请

PM 将完成度 % 更新为 **100%** 后，即向**客户经理（AM）**发出信号，提示可针对该里程碑生成**开票申请**。AM 审核开票明细后向财务提交开票申请。

### 5.5 按产品类别分配收入

对于包含混合产品类别（如硬件+软件+服务）的里程碑，应收金额可能按类别拆分。每个子类别在**开票明细**子选项卡中单独追踪。

### 5.6 付款状态标签

| 状态 | 含义 |
|------|------|
| 待处理（Pending） | 发票尚未开具 |
| 已开票（Invoiced） | 发票已开具，款项尚未收到 |
| 部分收款（Partially Paid） | 已收到部分款项，仍有余款未收 |
| 已收款（Paid） | 该里程碑全部款项已收齐 |

## 6. 常见问题与注意事项

**问：新的销售订单需要创建付款计划，我该怎么操作？**
付款计划无需手动创建，销售订单确认后系统自动生成。若某里程碑缺失，请检查销售订单的付款条款是否配置正确，如有需要请联系系统管理员。

**问：完成度 % 仍为 0%，但项目已经开始了，谁来更新？**
**项目经理（PM）** 负责更新完成度 %，请联系负责该项目的 PM 要求更新。

**问：已收金额有误，可以编辑付款计划记录吗？**
付款计划主字段为派生字段，无法直接编辑。付款金额通过回款（Collection）记录更新。请查看**付款明细**子选项卡，确认关联的回款记录是否正确。

**问：我已经开了发票，但"未开票金额"仍显示为正数，原因是什么？**
该发票可能尚未关联至此付款计划里程碑。请查看**开票明细**子选项卡，确认发票是否已正确关联。

**问：一个付款计划里程碑可以对应多张发票吗？**
可以。单个里程碑可以分批开票（如部分开票），每张发票在**开票明细**子选项卡中显示为单独一行。

**问：如何找出逾期未收的付款计划？**
在列表视图中使用**总未收应收金额**选项卡筛选，查看所有有未收余额的里程碑，对照关联销售订单付款条款中的预期回款日期进行核对。

**问：付款计划编号 `PP202604270002` 代表什么含义？**
- `PP` = 付款计划（Payment Plan）前缀
- `20260427` = 创建日期（2026 年 4 月 27 日）
- `0002` = 当天创建的第 2 条记录
