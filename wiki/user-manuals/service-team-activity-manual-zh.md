## 1. 模块概述

**服务团队（Service Team）** 和 **活动日志（Activity Log）** 是贯穿 CRM 所有客户相关记录的两个核心功能，适用于线索（Lead）、联系人（Contact）、客户（Customer）和商机（Opportunity）。

- **服务团队** — 控制哪些用户可以**查看和编辑**某条记录。若用户不在记录的服务团队中，则无法访问该记录。
- **活动日志** — 记录每次销售互动（电话、拜访、会议等），形成完整的沟通历史。

两项功能均可从任意详情页的**右侧边栏**访问，并在线索转化为商机时自动迁移。

## 2. 服务团队

### 2.1 什么是服务团队？

服务团队是有权访问某条特定记录的 CRM 用户列表。每条记录（线索、联系人、客户、商机）均维护各自独立的服务团队。加入某实体的团队**不会**自动授予访问相关实体的权限。

> "服务团队是指有权查看和编辑该详情页信息的人员。"

### 2.2 服务团队成员属性

| 属性 | 选项 | 默认值 | 说明 |
|------|------|--------|------|
| 成员 | 组织内任意用户 | — | 通过用户选择器选取 |
| 权限 | 只读 / 读写 | 读写 | 控制成员是否可编辑 |
| 团队角色 | 普通成员 | 普通成员 | 内部团队结构标签 |
| 项目角色 | 客户经理 | （未勾选） | 若该人员为客户负责人，可勾选 |

### 2.3 如何添加团队成员

1. 打开任意详情页（线索、联系人、客户或商机）。
2. 在右侧边栏找到**服务团队**面板。
3. 点击 **+ 添加**（若已有成员，则点击 **+ 继续添加**）。
4. 在**添加团队成员**弹窗中：
   - **成员**（\*）：选择要添加的用户。
   - **权限**（\*）：选择**只读**或**读写**。
   - **团队角色**：勾选**普通成员**（默认）。
   - **项目角色**：如适用，勾选**客户经理**。
5. 点击**确认**。

![添加团队成员弹窗——成员、权限、团队角色与项目角色字段](../assets/service-team-002.jpg)

新成员立即出现在服务团队列表中，并可按其权限级别访问该记录。

### 2.4 如何移除团队成员

1. 打开详情页。
2. 在服务团队面板中找到该成员。
3. 点击其姓名旁的**删除**（垃圾桶）图标。
4. 确认移除。

该用户立即失去对该记录的访问权限。

### 2.5 各实体中服务团队的位置

| 实体 | 位置 |
|------|------|
| 线索 | 线索详情页右侧边栏 |
| 联系人 | 联系人详情页右侧边栏 |
| 客户 | 客户详情页右侧边栏 |
| 商机 | 商机详情页右侧边栏 |

![服务团队面板——右侧边栏展示团队成员与权限级别](../assets/service-team-001.jpg)

### 2.6 权限级别说明

| 权限 | 可查看 | 可编辑 |
|------|--------|--------|
| 只读 | 是 | 否 |
| 读写 | 是 | 是 |

不在服务团队中的用户对该记录**无任何访问权限**。

## 3. 活动日志

### 3.1 什么是活动日志？

活动日志记录与某条记录相关的所有销售互动——电话沟通、上门拜访、会议洽谈等，形成可查阅的完整沟通时间线。

> "如果与客户通了电话或上门拜访，可以在这里记录。"

**命名说明**：该功能在线索、客户、商机中称为**活动日志（Activity Log）**，在联系人实体中称为**销售记录（Sales Record）**，但功能完全相同。

| 实体 | 选项卡 / 面板名称 |
|------|------------------|
| 线索 | 活动日志 |
| 联系人 | 销售记录 |
| 客户 | 活动日志 |
| 商机 | 活动日志 |

### 3.2 如何记录活动

1. 打开任意详情页（线索、联系人、客户或商机）。
2. 在右侧边栏找到**活动日志**（或**销售记录**）面板。
3. 点击**新建记录**（或**记录活动**）。
4. 填写活动表单：

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| 活动类型 | 是 | 下拉选择 | 例如"电话沟通"、"拜访"、"会议" |
| 联系人 | 是 | 关联查找 | 此次互动涉及的联系人 |
| 我方参与人 | 是 | 用户查找 | 自动填充为当前用户；可添加其他参与者 |
| 关联业务 | 否（自动） | 只读 | 自动填充为父记录名称 |
| 讨论详情 | 否 | 多行文本 | 互动备注（最多 1000 字） |
| 附件 | 否 | 文件上传 | 支持文件（如会议纪要、通话记录） |

5. 点击**提交**。

![活动日志时间线——展示已记录条目的类型徽章、时间戳和讨论详情](../assets/service-team-003.jpg)

日志条目立即显示在活动日志时间线上，包含时间戳、您的姓名和活动类型。

### 3.3 活动日志展示格式

每条日志条目显示：
- **日期**和**时间**
- **用户头像和姓名**
- **活动类型**徽章（例如蓝色的"电话沟通"）
- **讨论详情**（您填写的备注）
- **元数据**：联系人姓名和参与人姓名

## 4. 线索转化时的数据迁移

### 4.1 概述

将线索转化为联系人、客户和商机时，系统会在转化向导第二步提供**数据迁移（Carry Over Information）**选项，用于控制线索的服务团队成员和活动日志是否复制到新建记录中。

### 4.2 复制团队至

| 勾选项 | 效果 | 默认 |
|--------|------|------|
| 客户 | 将线索的服务团队复制到新建客户的服务团队 | 已勾选 |
| 联系人 | 将线索的服务团队复制到新建联系人的服务团队 | 已勾选 |
| 商机 | 将线索的服务团队复制到新建商机的服务团队 | 已勾选 |

### 4.3 复制活动至

| 勾选项 | 效果 | 默认 |
|--------|------|------|
| 客户 | 将线索的活动日志复制到客户的活动日志 | 已勾选 |
| 联系人 | 将线索的活动日志复制到联系人的销售记录 | 已勾选 |
| 商机 | 将线索的活动日志复制到商机的活动日志 | 已勾选 |

**最佳实践**：保持所有勾选框为默认选中状态，确保转化后每条相关记录都能查看完整的历史记录。

![线索转化数据迁移——复制团队与复制活动的勾选框](../assets/service-team-004.jpg)

### 4.4 迁移内容示例

```
线索
  服务团队：[Alice, Bob] → 复制至客户、联系人、商机
  活动日志：["2026-06-01 电话：讨论了需求"]
            → 复制至客户、联系人、商机
```

## 5. 业务规则与流程

### 5.1 服务团队按实体独立配置

加入客户的服务团队**不会**自动授予访问该客户旗下商机的权限。每个商机（以及线索、联系人）都有独立的服务团队，必须单独配置，或通过线索转化数据迁移来填充。

### 5.2 负责人与服务团队

记录的**负责人（Owner）**是对该记录负主要责任的人员。负责人通常会被自动加入服务团队，但请务必确认——尤其是在编辑或重新分配归属后。

### 5.3 只读与读写的使用建议

- 对需要更新记录的团队成员（销售代表、客户经理）授予**读写**权限。
- 对只需了解进展但不应修改的相关方（如管理层）授予**只读**权限。

### 5.4 活动日志最佳实践

- 每次重要的客户互动后应及时记录，保持历史记录的准确性。
- 在**讨论详情**字段中记录关键结论、后续行动或承诺事项。
- 通过**附件**字段上传会议纪要或通话记录，留存完整文档。

## 6. 常见问题与注意事项

**问：列表中可以看到某条线索，但无法打开，原因是什么？**
您未被加入该线索的服务团队。请联系该记录的负责人或管理员，申请至少添加为只读权限成员。

**问：我已加入客户的服务团队，但看不到该客户的商机，为什么？**
服务团队按实体独立配置。您需要由商机的负责人或管理员单独将您加入商机的服务团队。

**问：只读权限能记录活动日志吗？**
不能。记录活动日志属于编辑操作，需要读写权限。

**问：联系人里的"销售记录"和其他地方的"活动日志"是同一个功能吗？**
是的，功能完全相同，只是联系人实体使用了不同的名称。字段和操作流程均一致。

**问：线索转化后，商机的活动日志为空，即使已勾选"复制活动至"，怎么处理？**
这是已知问题。若转化后活动日志未出现在商机中，请联系系统管理员排查。

**问：服务团队成员数量有限制吗？**
目前无明确限制。建议添加所有相关人员，同时保持列表简洁，避免权责不清。

**问：添加成员后，可以修改其权限吗？**
可以。在服务团队面板中点击该成员行的**编辑**图标，修改权限设置即可。
