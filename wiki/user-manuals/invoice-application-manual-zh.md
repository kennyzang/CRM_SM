## 1. 模块概述

发票申请模块用于管理售后收款流程。它基于销售订单生成形式发票（Proforma Invoice），支持两种开票模式：**项目**（全额开票）和**里程碑**（按付款计划进度开票）。

### 1.1 入口路径

- **侧边栏**: 导航至 **REVENUE（收入） → Invoice Application（发票申请）**

### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| 项目开票 | 一次性开具销售订单全额发票 |
| 里程碑开票 | 针对特定付款里程碑进行进度开票 |
| PDF 预览 | 预览并导出形式发票为 PDF |
| 审批流程 | 数字签名与审批链 |
| 自动填充 | 行项目从销售订单继承 |

## 3. 创建发票申请

点击 **+ Create** 按钮打开发票申请创建页面。

![发票申请创建页面](../assets/ir-002.jpg)

### 3.1 基本信息部分

| 字段 | 必填 | 类型 | 描述 |
|------|------|------|------|
| 发票类型 | 是 (*) | 单选 | 选择 **项目** 或 **里程碑** |
| 发票申请编号 | 自动 | 只读 | 提交时自动生成 |
| 销售订单 | 是 (*) | 查找 | 选择来源销售订单 |
| 客户采购单号 | 否 | 文本 | 从销售订单继承，可编辑 |
| 实体 | 是 | 标签 | 如 SMMY |
| 联系人 | 否 | 查找 | 关联到销售订单客户 |
| 地址 | 否 | 查找 | 从联系人自动填充 |
| 负责人 | 是 (*) | 用户标签 | 自动填充为当前用户 |
| SP | 否 | 文本 | 如 "YCK" |
| 货币 | 自动 | 只读 | 从销售订单继承（如 MYR） |
| 商机 | 否 | 查找 | 父级商机 |
| 附件 | 否 | 上传 | 支持文档 |
| 备注 | 否 | 多行文本 | 附加说明 |

### 3.2 页眉部分

| 字段 | 必填 | 类型 | 描述 |
|------|------|------|------|
| PI 编号 | 自动 | 只读 | 自动生成 |
| 参考编号 | 自动 | 只读 | 自动生成 |
| 日期 | 是 | 日期选择器 | 默认为当天 |

### 3.3 客户（收件方）部分

| 字段 | 必填 | 类型 | 描述 |
|------|------|------|------|
| 公司名称 | 是 (*) | 查找 | 从销售订单自动填充 |
| 地址 | 否 | 文本 | 从客户预填 |
| 收件人 | 否 | 文本 | 联系人姓名 |
| 邮箱 | 否 | 文本 | 客户邮箱 |
| 电话 | 否 | 文本 | 客户电话 |

## 4. 项目类型发票

![项目发票 - 行项目](../assets/ir-003.jpg)

当 **发票类型 = 项目** 时，行项目从销售订单自动填充。

### 4.1 行项目表格

| 列名 | 描述 |
|------|------|
| 序号 | 行号 |
| 服务周期 | 如 "Year1" |
| 产品 | 销售订单中的产品名称 |
| 产品代码 | 如 "BIOR502-B4" |
| 描述 | 产品描述 |
| 数量 | 从销售订单 |
| 单价 | 从销售订单 |
| 不含服务税总额 | 数量 × 单价 |
| 服务税 8% | 自动计算 |
| 含税总额 | 自动计算 |

### 4.2 发票金额汇总

| 字段 | 描述 |
|------|------|
| 不含税总额 | 所有行项目总额之和 |
| 服务税 | 8% SST |
| 含税总额 | 总额 + 服务税 |

## 5. 里程碑类型发票

![里程碑发票 - 付款计划](../assets/ir-004.jpg)

当 **发票类型 = 里程碑** 时，需要选择一个付款计划记录。

### 5.1 里程碑表格

| 列名 | 描述 |
|------|------|
| 序号 | 行号 |
| 里程碑名称 | 如 "安装" |
| 应收百分比 | 总额的百分比 |
| 审批中发票 | 当前在审批中的金额 |
| 未开票金额 | 尚未开票的金额 |
| 付款计划编号 | 点击打开选择记录模态框 |

### 5.2 选择记录模态框

![选择付款计划](../assets/ir-005.jpg)

点击付款计划编号字段打开选择模态框。

**筛选选项**:
- 销售订单编号
- 付款类型
- 应收金额
- 应收百分比
- 付款计划编号

**选择一条记录**并点击 **确认** 将其关联到发票。

## 6. 发票详情与 PDF 导出

![PDF 预览模态框](../assets/ir-006.jpg)

### 6.1 查看发票详情

提交后，点击列表中的任意记录查看详情。

### 6.2 PDF 预览

点击 **Export PDF** 打开 PDF 预览模态框：

- **公司 Logo**: SECURE METRIC TECHNOLOGY
- **文档标题**: Proforma Invoice（形式发票）
- **收件方信息**: 公司名称、地址、联系方式
- **发票元数据**: 日期、条款、销售代表、参考号、PI 编号
- **行项目表格**: 产品代码、描述、数量、单价、税额、总额
- **财务汇总**: 不含税总额、8% 服务税、含税总额
- **条款与条件**: 标准条款

### 6.3 导出 PDF

点击 **Export PDF** 按钮将形式发票下载为 PDF 文件。

## 7. 审批流程

![审批流程侧边栏](../assets/ir-007.jpg)

审批流程侧边栏位于创建/详情页面的右侧。

### 7.1 审批步骤

1. **Track（追踪）**: 从下拉菜单选择工作流操作
2. **Comments（评论）**: 输入处理意见
3. **Digital Signature（数字签名）**: 系统从您的个人资料自动捕获签名
4. **Submit（提交）**: 点击提交按钮触发审批流程

### 7.2 签名管理

- **Preview（预览）**: 查看您的签名
- **Delete（删除）**: 移除当前签名（下次提交时将重新捕获）

### 7.3 附加选项

- **Common Comments（常用意见）**: 快速插入标准评论
- **Upload attachment（上传附件）**: 添加支持文档
- **Expand approval options（展开审批选项）**: 查看自定义审批链

## 8. 常见问题与注意事项

### 8.1 项目开票和里程碑开票有什么区别？

- **项目开票**: 一次性开具销售订单全额发票。包含所有行项目。
- **里程碑开票**: 针对特定付款里程碑进行开票。选择要开票的里程碑。

### 8.2 为什么某些字段是自动填充的？

货币、客户名称和行项目等字段从销售订单继承，以确保数据一致性并减少手动输入。

### 8.3 8% 服务税是什么？

系统自动对所有发票金额应用 8% SST（销售与服务税），符合马来西亚税收法规要求。

### 8.4 提交后可以编辑发票吗？

提交后，发票进入审批流程。编辑可能需要撤回提交或等待审批完成。

### 8.5 已知问题

- **界面拼写错误**: "Univoiced Amount" 应为 "Uninvoiced Amount"
