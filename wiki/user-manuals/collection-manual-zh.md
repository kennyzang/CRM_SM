## 1. 模块概述

**客户回款（Collection）** 模块（也称**客户付款**模块）用于记录客户针对未结应收款项所支付的实际款项。每条回款记录记录一笔具体的到账款项，包括金额、日期、负责人员及银行回单凭证。

回款记录与付款计划模块关联，将更新对应里程碑的**已收金额**并减少**未收金额**。

### 1.1 入口

| 入口 | 路径 |
|------|------|
| 独立列表 | 左侧导航 → **收入（REVENUE）** → **客户付款（Customer Payment / Collection）** |

### 1.2 核心功能

- 记录客户每笔到账款项
- 将付款与特定客户关联
- 上传银行回单作为凭证
- 路由至财务进行确认
- 确认后锁定记录，防止进一步编辑
- 将回款金额回写至付款计划追踪

## 3. 创建回款记录

### 3.1 打开表单

进入左侧导航 → **收入（REVENUE）** → **客户付款（Collection）**，点击 **+ 新建**。

### 3.2 字段说明

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| 客户名称 | 是 | 关联查找 | 选择支付款项的客户 |
| 付款日期 | 是 | 日期/时间选择器 | 款项到账的日期和时间 |
| 回款金额 | 是 | 金额输入框 | 本次交易实际到账金额 |
| 结算货币 | 是 | 动态配置下拉 | 付款货币（如 MYR、USD） |
| 提醒日期 | 否 | 日期/时间选择器 | 若为部分付款或待确认，设置跟进日期 |
| 负责人 | 否 | 地址选择器（用户） | 负责此回款的销售代表，默认为当前用户 |
| 部门 | 否 | 地址选择器（组织单元） | 负责此回款的部门 |
| 财务确认人 | 否 | 地址选择器（用户） | 将确认收款的财务人员 |
| 财务确认时间 | 否 | 日期/时间选择器 | 财务确认时间（可由工作流自动设置） |
| 付款用途 | 否 | 下拉（单选） | 付款原因或类别（如发票结算、预付款） |
| 锁定状态 | 否 | 单选按钮 | 锁定 / 解锁——通常在财务确认后设置 |
| 银行回单附件 | 否 | 文件上传 | 银行转账凭证或收款回单的扫描件 |

### 3.3 保存

点击顶部操作栏中的 **保存**。记录创建完成并出现在列表中，关联的付款计划里程碑中的已收金额将随之更新。

## 5. 业务规则与流程

### 5.1 标准回款流程

```
客户汇款 → 客户经理创建回款记录
→ 填写客户名称 + 付款日期 + 回款金额 + 结算货币
→ 上传银行回单附件
→ 指定财务确认人
→ 保存
→ 财务审核并确认收款
→ 记录财务确认时间
→ 锁定记录
```

### 5.2 客户关联

每条回款记录必须关联至一个**客户**。客户名称字段使用关联查找——在现有客户数据库中搜索并选择，不可直接输入文本名称，必须是有效的 CRM 客户记录。

### 5.3 财务确认为必要步骤

客户经理保存回款记录后，指定的**财务确认人**需审核银行回单附件和金额。核实无误后：
- 记录**财务确认时间**。
- 该回款记录正式确认。
- PM/AM 可推进里程碑关闭。

### 5.4 银行回单附件

银行回单（转账凭证或银行确认函）是主要凭证文件。尽管界面未将该字段标为硬性必填，但按**业务规范**，超过一定金额的款项必须上传回单。请在提交财务确认前上传回单。

### 5.5 确认后锁定

财务确认后：
- 将**锁定状态**设置为**已锁定**。
- 记录变为只读。
- 锁定记录除管理员外无法编辑或删除。

锁定机制防止已确认财务记录被意外修改，维护审计日志的完整性。

### 5.6 结算货币

使用**结算货币**字段记录客户实际汇款的货币，可能与发票货币不同（如涉及跨币种付款）。外汇换算由财务团队处理。

### 5.7 付款用途

**付款用途**字段用于对付款原因进行分类，常见值包括：
- 发票结算
- 预付款
- 押金

正确分类有助于准确的收入报告和账务对账。

## 6. 常见问题与注意事项

**问：客户已付款，但在客户名称字段找不到该客户，怎么办？**
客户必须以记录形式存在于 CRM 中。若客户尚未创建，请先创建客户记录，再返回创建回款记录。

**问：可以记录部分付款吗？**
可以。在**回款金额**字段中填写实际到账金额。若剩余款项将在后续收到，等下次到账时再创建新的回款记录。

**问：应该指定谁作为财务确认人？**
应指定负责对账到账款项的财务团队成员，请联系财务部门确认合适的人选。

**问：记录已锁定，但需要更正，怎么办？**
请联系财务部门或系统管理员解锁记录，解锁已确认的财务记录需要适当的授权。

**问：是否需要同时在回款模块和付款计划中操作？**
不需要。创建回款记录后，关联付款计划的已收金额将自动更新，无需手动修改付款计划。

**问：客户用与发票不同的货币付款，应使用哪种货币？**
在结算货币字段记录**实际收款货币**，在回款金额字段填写**实际收到的金额**。财务团队将单独处理汇率换算，并以相应货币记账。

**问：同一张发票可以创建多条回款记录吗？**
可以。若客户分期付款或多次部分付款，每笔付款应单独创建一条回款记录。所有关联同一客户的记录将在付款计划中汇总统计。
