## 核心 API 说明

### MKXFORM 关键方法

| API 名称 | 适用场景 | 说明 |
|---------|---------|------|
| `MKXFORM.setValue(fieldId, value)` | 主表 | 直接设置主表单字段值 |
| `MKXFORM.updateControl(fieldId, rowIndex, value)` | 明细表 | 设置明细表指定行字段值 |
| `MKXFORM.$(fieldId)` | 通用 | 获取组件实例 |
| `cmp._CURRENT_FIBRE.props` | 通用 | 获取组件属性对象 |

### 优先级

主表优先使用 `MKXFORM.setValue`，若不可用则回退到 UI 交互。
明细表优先使用 `MKXFORM.updateControl`，若不可用则回退到 UI 交互。

## 基础数据（Cfg）说明

### 数据获取

接口：`POST /sys-xform/sysXFormCfgData/findByEnum`

参数：

```typescript
{
  enumId: cfgId,
  pageRequest: { pageSize: 1000, pageNo: 1 }
}
```

### 值格式

单选/多选格式：`[{ fdId: string, fdName: string }]`

### 明细表填充

主表：`MKXFORM.setValue(fieldId, [{ fdId, fdName }])`

明细表：`MKXFORM.updateControl(fieldId, rowIndex, [{ fdId, fdName }])`

## 字段标识说明

### fieldId 格式

| 场景 | 格式 | 示例 |
|------|-----|-----|
| 主表字段 | `{formId}.{fieldId}` | `mk_model_xxx.fd_name` |
| 明细表字段（cfg） | `{detailTableId}.{fieldId}~{rowKey}` | `mk_model_xxx_d_xxx.fd_name~xxx` |
| 明细表字段（普通） | `{detailTableId}.{fieldId}` | `mk_model_xxx_d_xxx.fd_name` |

### rowIndex

明细表行索引，从 0 开始。

## 组件属性访问

```typescript
// 1. 获取组件
const cmp = window.MKXFORM.$(fieldId);

// 2. 获取组件 fiber
const fibre = cmp._CURRENT_FIBRE;

// 3. 获取属性
const props = fibre.props;

// 4. 调用 onChange 设置值
props.onChange(value);

// 5. 调用 onBlur（如果需要）
if (typeof props.onBlur === 'function') {
  props.onBlur(event);
}

// 6. 调用 onFocus（如果需要）
if (typeof props.onFocus === 'function') {
  props.onFocus(event);
}
```
