# EasyCraft 表单测试框架设计方案

## 一、核心目标

| 目标 | 描述 |
|------|------|
| **极简新增** | 新增测试用例代码量最少，只需提供 URL + 字段配置 |
| **自动探查** | AI 自动分析 DOM 结构，生成/更新表模型 |
| **模型复用** | 表模型持久化，后续测试直接引用 |
| **快速定位** | 单选/多选/下拉等动态选项支持多种定位策略 |

## 三、模块设计

### 3.1 表模型定义（Schema）

```typescript
// src/schema/types.ts

export interface FieldSchema {
  /** 字段标识 */
  key: string;
  /** 字段标签名 */
  label: string;
  /** 控件类型 */
  type: 'text' | 'textarea' | 'radio' | 'checkbox' | 'select' | 'multi-select' | 'date' | 'time' | 'number' | 'money';
  /** 定位器（支持多种策略） */
  locator: {
    /** 主定位器：CSS选择器、data-tid、xpath 等 */
    primary?: string;
    /** 备选定位器列表（按优先级） */
    fallbacks?: string[];
  };
  /** 动态选项（首次探查时获取） */
  options?: Array<{
    value: string;
    label: string;
    /** 定位器 */
    selector?: string;
  }>;
  /** 额外属性 */
  meta?: Record<string, any>;
}

export interface FormSchema {
  /** 表单唯一标识（从URL或用户指定） */
  id: string;
  /** 表单名称 */
  name: string;
  /** 表单URL */
  url: string;
  /** 字段映射 */
  fields: Record<string, FieldSchema>;
  /** 创建时间 */
  createdAt: string;
  /** 更新时间 */
  updatedAt: string;
}
```

### 3.2 SchemaDiscovery（自动探查）

```typescript
// src/schema/SchemaDiscovery.ts

export class SchemaDiscovery {
  /**
   * 自动探查表单结构
   * @param page Playwright Page
   * @param config 探查配置
   */
  static async discover(page: Page, config: {
    url: string;
    credentials?: { username: string; password: string };
  }): Promise<FormSchema>
}
```

**探查策略：**
1. 访问页面 → 等待加载
2. 遍历表单容器（`.ele-xform-fieldset-wrap`）
3. 提取 `data-id`（表名.字段名）
4. 分析控件类型和结构
5. **针对动态选项**：点击展开获取所有选项文本
6. 生成 `FieldSchema`
7. 保存到注册表

## 七、关键设计决策

### 7.1 为什么不继续用现有的 FormEngine？

| 问题 | 说明 |
|------|------|
| 耦合太紧 | FormEngine、ControlFactory、ControlRegistry 三层耦合 |
| 定位策略分散 | 每个控件 handler 都有自己的定位逻辑，难以统一管理 |
| 难以扩展 | 新增控件需要修改多个文件 |
| 模型不持久化 | 每次测试都要重新探查 |

### 7.2 新的设计优势

| 优势 | 说明 |
|------|------|
| **模型驱动** | 探查一次，持久化，多次使用 |
| **定位器集中** | 定位策略统一管理，支持降级 |
| **用户极简** | 只需提供数据，探查和填充自动完成 |
| **可调试** | 模型文件可手动编辑，便于排查问题 |

### 7.3 动态选项处理

```typescript
// SelectFiller 示例
class SelectFiller {
  async fill(page: Page, selector: string, value: string): Promise<boolean> {
    // 1. 点击触发器展开下拉
    await page.locator(selector).click();
    
    // 2. 等待弹窗出现（最多 3 秒）
    await page.waitForSelector('.lui-select-dropdown, [role="listbox"]', {
      state: 'visible',
      timeout: 3000
    });
    
    // 3. 查找选项（多种策略）
    const optionSelectors = [
      `.lui-select-item:has-text("${value}")`,      // 精确包含
      `[title="${value}"]`,                           // title 属性
      `li:has-text("${value}")`,                     // 通用 li
    ];
    
    for (const sel of optionSelectors) {
      const option = page.locator(sel).first();
      if (await option.isVisible()) {
        await option.click();
        return true;
      }
    }
    
    return false;
  }
}
```

### 7.4 动态选项处理方案

#### 用户输入语法

| 语法 | 说明 | 示例 |
|------|------|------|
| `值` | 精确匹配 | `fd_sex: '男'` |
| `'?'` | 随机选择 | `fd_city: '?'` |
| `'?N'` | 随机选N个 | `fd_hobby: '?2'` |
| `'#N'` | 选择第N个 | `fd_sex: '#2'` |
| `'*:关键字'` | 包含关键字 | `fd_status: '*:启用'` |
| `'!排除'` | 排除选项 | `fd_level: '!禁用'` |
| `'#first'` | 选第一个 | `fd_sex: '#first'` |
| `'#last'` | 选最后一个 | `fd_sex: '#last'` |
| `['值1', '值2']` | 多选数组 | `fd_hobby: ['篮球', '足球']` |

#### OptionMatcher 实现

```typescript
// src/filler/dynamic/OptionMatcher.ts

export type ValueStrategy = 
  | { type: 'exact'; value: string }
  | { type: 'random'; count: number }
  | { type: 'index'; index: number }
  | { type: 'contains'; keyword: string }
  | { type: 'exclude'; exclude: string[] }
  | { type: 'first' }
  | { type: 'last' };

export class OptionMatcher {
  static parse(value: any): ValueStrategy {
    if (value === '?' || value === true) return { type: 'random', count: 1 };
    if (value === '#first') return { type: 'first' };
    if (value === '#last') return { type: 'last' };
    
    if (typeof value === 'string') {
      if (value.startsWith('?')) return { type: 'random', count: parseInt(value.slice(1)) || 1 };
      if (value.startsWith('#')) return { type: 'index', index: parseInt(value.slice(1)) - 1 };
      if (value.startsWith('*:')) return { type: 'contains', keyword: value.slice(2) };
      if (value.startsWith('!')) return { type: 'exclude', exclude: value.slice(1).split(',') };
      return { type: 'exact', value };
    }
    
    if (typeof value === 'number') return { type: 'index', index: value - 1 };
    
    return { type: 'exact', value: String(value) };
  }
  
  static match(options: Option[], strategy: ValueStrategy): string[] {
    switch (strategy.type) {
      case 'exact':
        return options.filter(o => o.text === strategy.value).map(o => o.text);
      case 'contains':
        return options.filter(o => o.text.includes(strategy.keyword)).map(o => o.text);
      case 'first':
        return [options[0]?.text].filter(Boolean);
      case 'last':
        return [options[options.length - 1]?.text].filter(Boolean);
      case 'index':
        return [options[Math.max(0, strategy.index)]?.text].filter(Boolean);
      case 'random':
        return [...options].sort(() => Math.random() - 0.5)
          .slice(0, strategy.count).map(o => o.text);
      case 'exclude':
        return options.filter(o => !strategy.exclude.some(e => o.text.includes(e))).map(o => o.text);
    }
  }
}
```

#### SelectHandler 下拉处理

```typescript
// src/filler/dynamic/SelectHandler.ts

export class SelectHandler {
  /** 展开下拉并获取所有选项 */
  static async getOptions(page: Page, triggerSelector: string): Promise<Option[]> {
    await page.locator(triggerSelector).click();
    const popup = page.locator('.lui-select-dropdown, [role="listbox"]');
    await popup.waitFor({ state: 'visible', timeout: 3000 });
    
    const options = await popup.locator('li, [role="option"]').all();
    const result: Option[] = [];
    
    for (const opt of options) {
      const text = (await opt.textContent())?.trim();
      if (text) result.push({ text, element: opt });
    }
    
    await page.keyboard.press('Escape');
    return result;
  }
  
  /** 根据策略选择选项 */
  static async select(
    page: Page, 
    triggerSelector: string, 
    strategy: ValueStrategy,
    isMulti: boolean = false
  ): Promise<string[]> {
    await page.locator(triggerSelector).click();
    const popup = page.locator('.lui-select-dropdown, [role="listbox"]');
    await popup.waitFor({ state: 'visible', timeout: 3000 });
    
    const selected: string[] = [];
    const selectors = this.buildSelectors(strategy);
    
    for (const selector of selectors) {
      const options = page.locator(selector);
      const count = await options.count();
      
      if (count > 0) {
        const targetCount = strategy.type === 'random' ? strategy.count : Math.min(count, 1);
        for (let i = 0; i < targetCount; i++) {
          const text = await options.nth(Math.floor(Math.random() * count)).textContent();
          await options.first().click();
          selected.push(text?.trim() || '');
        }
        break;
      }
    }
    
    if (!isMulti) await page.keyboard.press('Escape');
    return selected;
  }
  
  private static buildSelectors(strategy: ValueStrategy): string[] {
    const base = '.lui-select-dropdown li, [role="listbox"] [role="option"]';
    switch (strategy.type) {
      case 'exact': return [`${base}:has-text("${strategy.value}")`, `[title="${strategy.value}"]`];
      case 'contains': return [`${base}:has-text("${strategy.keyword}")`];
      case 'first': return [`${base}:first-child`];
      case 'last': return [`${base}:last-child`];
      case 'index': return [`${base}:nth-child(${strategy.index + 1})`];
      default: return [base];
    }
  }
}
```
