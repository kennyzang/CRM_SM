# 表单测试流程文档

本文档详细说明如何新增一个表单测试，以及整个流程中 AI 驱动和 Playwright 驱动的分工。

---

```

│ 1. 表单ID (formId)                                          │

│                                                             │

```

│         │                   │                    │                   │
│         ▼                   ▼                    ▼                   │

## 三、AI 驱动 vs Playwright 驱动的分工

| 阶段 | AI 驱动 | Playwright 驱动 |
|------|---------|-----------------|
| **Schema 生成** | ✅ 探查 DOM 结构，识别字段类型 | ✅ 执行页面操作，提取元素信息 |
| **Schema 存储** | ✅ 生成 JSON 文件 | ❌ |
| **Schema 加载** | ❌ | ✅ 读取本地 JSON |
| **页面导航** | ❌ | ✅ 执行 `page.goto()` |
| **字段填充** | ❌ | ✅ 调用 Filler 执行点击、输入 |
| **表单提交** | ❌ | ✅ 执行点击提交按钮 |
| **结果验证** | ❌ | ✅ 断言验证 |

## 五、快速新增测试用例模板

```typescript
// tests/my-new-form.spec.ts
import { test, expect } from '@playwright/test';
import { FormTestBuilder, RowData } from '../src/core/FormTestBuilder';

const FORM_ID = 'your_form_id_here';
const FORM_NAME = 'Your Form Name';
const FORM_URL = 'https://test.easycraft.ai/web/#/current/.../add/...';
const DETAIL_TABLE_ID = 'your_form_id_d_detailId'; // 如有明细表

test.describe('Your Form — 测试', () => {
  let builder: FormTestBuilder;

  test.beforeEach(async ({ page }) => {
    builder = new FormTestBuilder(page, {
      formId: FORM_ID,
      formName: FORM_NAME,
      url: FORM_URL,
      schemaPath: './schemas',
      detailTables: DETAIL_TABLE_ID ? [
        { detailModelId: DETAIL_TABLE_ID, detailTableName: 'Detail Table' }
      ] : undefined
    });
    await builder.initialize(); // 首次会自动生成 Schema
  });

  // 方式1: 随机数据填充
  test('随机数据测试', async ({ page }) => {
    await builder.navigate();
    await builder.fillAll(2); // 主表 + 明细表2行随机数据
    await builder.submit();
    
    // 验证
    const isSuccess = await page.locator('.ele-message-success').isVisible().catch(() => false);
    expect(isSuccess).toBeTruthy();
  });

  // 方式2: 自定义数据填充
  test('自定义数据测试', async ({ page }) => {
    await builder.navigate();
    await builder.fillAllFields(); // 只填充主表
    
    // 自定义明细表数据
    const detailData: RowData[] = [
      {
        'field_id_1': '文本值',
        'field_id_2': 123,
        'field_id_3': '2024-01-15',
        'field_id_4': [0, 1], // 多选
      }
    ];
    await builder.fillDetailTableWithData(detailData);
    
    await builder.submit();
  });
});
```

## 六、数据格式说明

### 6.1 RowData 类型

```typescript
export type RowData = Record<string, string | number | string[] | number[]>;
```

### 6.2 字段值格式对照表

| 字段类型 | fdType | 数据格式示例 | 说明 |
|---------|--------|-------------|------|
| 单行文本 | fd_input | `'文本内容'` | 字符串 |
| 多行文本 | textarea | `'多行内容\n第二行'` | 字符串，支持换行 |
| 数值 | numbertext | `123` 或 `123.45` | 数字 |
| 金额 | moneytext | `1000.50` | 数字 |
| 日期 | timestamp | `'2024-01-15'` | 字符串，YYYY-MM-DD 格式 |
| 时间 | timepicker | `'09:30'` | 字符串，HH:MM 格式 |
| 单选 | radio | `0` 或 `1` | 数字，选项索引 |
| 多选 | checkbox | `[0, 1]` 或 `[2]` | 数组，选项索引数组 |
| 下拉 | select | `0` | 数字，选项索引 |

## 七、总结

| 你需要做什么 | 框架会做什么 |
|-------------|-------------|
| 提供表单基本信息 (ID, URL) | 自动生成/加载 Schema |
| 编写测试用例逻辑 | 自动填充所有字段 |
| 定义自定义测试数据 (可选) | 自动处理明细表增行 |
| 运行测试命令 | 自动提交并验证结果 |

**一句话总结**: 你只需提供表单的基本信息，Schema 生成和字段填充逻辑都由框架自动处理。首次运行时会 AI 驱动生成 Schema，后续直接使用缓存的 Schema 进行 Playwright 驱动的自动化测试。
