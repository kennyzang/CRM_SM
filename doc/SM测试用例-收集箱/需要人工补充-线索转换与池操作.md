## 二、需要人工补充的测试点

### 1. 线索转换 — 弹窗 Step 2（Opportunity 步骤）字段核查

- [ ] 哪些是必填需要手动填的？
- [ ] 字段映射规则：线索的 `fd_xx` → 机会的哪个 `fd_xx`？

**操作**：在浏览器中手动触发一次 Convert → 进入 Step 2 后截图，把字段逐一记录下来，然后补充到脚本里。

### 2. 线索转换 — 新客户场景严格验证
- [ ] 客户列表确实新增了一条记录  
  **方法**: 脚本已输出 `custName`，去客户列表搜索确认
- [ ] 注册码正确  
  **方法**: 用 `regCode` 搜索
- [ ] 客户类型与选择一致
- [ ] 客户页签中的线索数 +1、商机数 +1  
  **方法**: 进入客户详情，查看各 tab 计数
- [ ] 点击页签内记录可跳转
- [ ] 线索锁定后不可再次 Convert / Edit

### 3. 线索转换 — 老客户场景验证
- [ ] 团队是否从线索带过来？（取决于系统配置）
- [ ] 销售记录是否从线索带过来？
- [ ] 客户原来不在公海池 → 转换后是否进入公海池？
- [ ] 线索的产品传递到商机的 PA 表是否正确

### 4. 线索转换 — 联系人验证
